# 高尔夫练习场 - 器材借用与归还验收系统

> 一体化管理高尔夫练习场器材借用、归还验收、连续回查的综合管理平台

## 项目简介

本系统将**器材借用、归还验收、球道预约和储值扣减**整合在同一平台，解决了传统管理中数据分散、上下文割裂的问题。一线处理和管理回看基于同一套数据，避免复盘时的信息不对称。

**核心解决的痛点：**
- ✅ 器材借用、归还验收、球道预约、储值扣减不再拆着看
- ✅ 同一件事不用在几个地方反复找，统一数据入口
- ✅ 场馆经理、教练主管、前台基于同一套数据协作，不再靠聊天工具拼接上下文
- ✅ 消耗口径一致、投诉回查有完整上下文、归还验收不遗漏

## 核心功能

### 1. 工作仪表盘（首页）
**一进门就能看见所有待办，不让首页空着**
- **待处理概览**：待审批借用、借用中、已逾期、今日驳回等关键指标
- **待回查记录**：需要后续跟进的归还记录（设备损坏、赔偿争议等）
- **已驳回记录**：今日驳回的借用申请，便于追踪
- **投诉与争议**：待处理客户投诉和纠纷案件
- **快速入口**：从首页一键跳转各功能模块

### 2. 借用管理
- 器材借用申请与审批流程
- 关联球道预约信息展示
- 押金管理和状态追踪
- 支持按状态筛选和搜索
- **角色权限控制**：前台和经理可审批，教练仅可查看自己申请的记录

### 3. 归还验收
- 器材状况评估（优秀/良好/一般/较差）
- 常见问题快速勾选（划痕、凹痕、配件缺失等）
- 问题记录和赔偿处理
- 押金退还自动计算
- 验收结果永久记录
- **角色权限控制**：前台和经理可执行验收，教练仅可查看

### 4. 连续回查面板
**统一搜索，关联展示，再也不用拼接上下文**
- **统一搜索**：按会员姓名、手机号、业务单号（借用单/预约单/储值单）搜索
- **关联展示**：借用记录、球道预约、储值变动在同一页面展示
- **时间线视图**：按时间顺序呈现完整业务上下文
- **详情面板**：点击查看每条记录的详细信息
- **一键跳转**：从案件详情直接跳转到完整回查

### 5. 投诉回查
- 客户投诉与争议案件管理
- 处理时间线追踪，完整记录每一步操作
- 关联借用记录快速跳转
- 支持添加处理备注和状态更新
- **角色权限控制**：仅经理可新建案件和更改状态

### 6. 角色切换
**不同岗位看到不同的操作界面和数据范围**
- **前台**：日常借用归还操作，可处理验收
- **教练**：教学相关视角，仅可查看自己申请的记录
- **经理**：拥有审批、处理争议、查看所有数据的完整权限

### 7. 边缘状态处理
**不只是一堆能点的组件，要把异常流程也做顺**
- 加载状态（Loading）：带骨架屏效果的加载动画
- 空状态（无数据）：友好的空状态提示和操作引导
- 搜索无结果状态：明确的无结果提示和建议
- 错误重试机制：错误状态下可一键重试

## 技术栈

- **框架**: Next.js 14 (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS

- **状态管理**: React Context

## 🎯 关键设计理念

### 数据一致性
- 借用、预约、储值数据通过 **会员ID** 强关联
- 连续回查页面整合展示所有关联数据，彻底避免信息孤岛
- 所有操作都有时间戳和操作人记录，便于审计追溯

### 用户体验
- **角色驱动**：不同岗位看到不同的操作界面和数据范围
- **状态驱动**：清晰的状态徽章和流转提示，避免误操作
- **边缘处理**：完善的加载、空状态、错误处理，异常流程也顺畅

### 业务流程闭环
1. **借用流程**：申请 → 审批 → 器材借出 → 状态更新
2. **归还流程**：归还验收 → 状况评估 → 问题记录 → 赔偿处理 → 押金退还
3. **争议流程**：投诉受理 → 上下文追溯 → 调查处理 → 结案归档

## 💻 开发说明

项目使用 Next.js 14 App Router，所有页面默认是 Server Component。需要客户端交互的页面（使用状态、事件等）顶部添加 `"use client"` 指令。

### 添加新页面

在 `src/app` 目录下创建对应文件夹和 `page.tsx` 文件即可，Next.js 会自动生成路由。

### 修改模拟数据

编辑 `src/lib/mockData.ts` 文件添加或修改模拟数据，类型定义在 `src/types/index.ts`。

### 角色权限扩展

在 `src/lib/context/AppContext.tsx` 中添加新的权限属性，并在各页面中使用。
