# 留学服务 - 签证进度与补件回查系统

一个专为留学服务机构设计的签证进度管理系统，解决共享盘、待办表和家长群消息并行管理带来的信息断层问题。

## ✨ 功能特性

### 📊 工作台仪表板
- **待处理案件** - 一目了然查看今日需处理的签证申请
- **已驳回案件** - 快速定位需要重新处理的申请
- **需回查补件** - 跟踪所有补件进度，避免遗漏
- **本周将到期** - 截止日预警，防止逾期

### 📋 签证进度管理
- 完整的7步签证流程时间线
- 实时进度显示和状态追踪
- 多维度筛选和搜索功能
- 案件详情页，包含完整上下文

### 📎 补件回查中心
- 补件材料统一管理
- 版本追踪，避免混乱
- 审核状态实时更新
- 一键催办功能

### 💰 退款协商
- 退款申请全流程管理
- 材料清单和上传状态
- 沟通记录完整留存
- 上下文完整，避免扯皮

### 📁 材料管理
- 分类文件管理
- 版本历史追踪
- 快速搜索和筛选

### 📈 数据报表
- 签证通过率统计
- 目的地分布分析
- 处理时效分析
- 团队绩效数据

### 👥 角色权限系统
- **顾问主管** - 全局视图、报表、退款管理
- **文案老师** - 签证进度、材料管理、补件回查
- **签证助理** - 签证进度、补件回查

## 🚀 快速开始

### 环境要求
- Node.js >= 16.0.0
- npm >= 7.0.0

### 安装依赖

#### 1. 后端服务
```bash
cd jewelry-system/backend
npm install
```

#### 2. 前端应用
```bash
cd jewelry-system/frontend
npm install
```

### 启动项目

#### 方式一：分别启动

**启动后端服务** (终端1):
```bash
cd jewelry-system/backend
npm start
```
后端API将运行在 `http://localhost:5000`

**启动前端应用** (终端2):
```bash
cd jewelry-system/frontend
npm run dev
```
前端应用将运行在 `http://localhost:3000`

#### 方式二：使用启动脚本
```bash
# 项目根目录
cd jewelry-system

# 安装所有依赖并启动
npm run setup && npm run dev
```

## 🔌 API 接口

### 健康检查
```
GET /api/health
```

### 签证案件
```
GET    /api/cases              # 获取案件列表
GET    /api/cases/:id          # 获取案件详情
POST   /api/cases/:id/notes    # 添加备注
```

### 补件管理
```
GET    /api/supplements        # 获取所有补件
POST   /api/cases/:id/supplements/:supplementId/upload  # 上传补件
```

### 退款管理
```
GET    /api/refunds            # 获取退款申请列表
```

### 通知中心
```
GET    /api/notifications      # 获取通知列表
```

### 仪表板统计
```
GET    /api/dashboard/stats    # 获取仪表板统计数据
```

## 📝 使用说明

### 角色切换
点击页面右上角的「角色: XXX」按钮，可以在三个角色间切换：
- 顾问主管 - 看到所有菜单和功能
- 文案老师 - 看不到退款和报表
- 签证助理 - 只能看到签证进度和补件回查

### 快速筛选
工作台的统计卡片可以点击，直接跳转到对应筛选结果的列表页。

### 侧边栏
侧边栏可以点击左上角的箭头折叠，获得更大的操作空间。

### 通知中心
点击侧边栏底部的「通知中心」，可以查看最新的预警和提醒。

## 🤝 常见问题

### Q: 如何重置演示数据？
A: 刷新页面即可，系统使用内存数据，不持久化存储。

### Q: 上传的文件会保存吗？
A: 演示版本不会真实保存文件，仅展示交互流程。

### Q: 可以添加新的签证案例吗？
A: 演示版本未实现创建功能，可查看已有案例。
