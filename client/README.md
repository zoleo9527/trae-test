# 水果批发赊销管理系统

一套面向水果批发行业的赊销账龄与回款催办管理系统，解决日常运营中过磅单、冷库表、客户信息分散，赊销结算流程不一致，回款催办滞后等痛点。

## 功能特性

### 核心模块

1. **工作台 (Dashboard)**
   - 待处理任务一览
   - 已驳回事项回查
   - 逾期账款预警
   - 快捷操作入口
   - 客户信用概览

2. **过磅单管理**
   - 新建采购过磅单
   - 毛重/皮重/净重自动计算
   - 过磅单确认审核
   - 关联冷库入库

3. **冷库库存**
   - 实时库存监控
   - 温湿度记录
   - 保质期预警
   - 分级状态跟踪

4. **分级配货**
   - 水果质量分级 (A/B/C/D)
   - 分级定价计算
   - 分级进度管理
   - 库存分配

5. **客户管理**
   - 客户档案管理
   - 信用等级评定 (S/A/B/C)
   - 信用额度设置
   - 历史订单追踪

6. **赊销账龄**
   - 赊销订单创建
   - 账龄分析 (未到期/逾期30天/60天/90天+)
   - 到期日计算
   - 信用状态自动更新

7. **回款催办**
   - 催办任务管理
   - 多种催办方式 (电话/上门/短信/律师函)
   - 催办记录追踪
   - 回款确认

8. **损耗管理**
   - 损耗记录上报
   - 损耗原因分类
   - 审核确认流程
   - 驳回反馈

9. **客诉赔付**
   - 投诉工单管理
   - 凭证上传
   - 处理流程跟踪
   - 赔付方案记录

### 角色权限

| 角色 | 权限 |
|------|------|
| 业务经理 | 全部模块 |
| 销售员 | 工作台、过磅单、客户、赊销、回款催办、客诉 |
| 库管员 | 工作台、过磅单、冷库、分级、损耗 |
| 财务 | 工作台、赊销、回款催办、客户 |
| 采购员 | 工作台、过磅单、冷库、客户 |

## 技术栈

- **前端框架**: React 18
- **构建工具**: Vite 5
- **路由管理**: React Router v6
- **样式方案**: Tailwind CSS 3
- **图标库**: Lucide React

## 快速开始

### 环境要求

- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装与启动

```bash
# 进入项目目录
cd client

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

启动后访问: http://localhost:5173

## 业务流程

### 采购入库流程
1. 采购员创建过磅单 → 2. 确认过磅单 → 3. 自动入库冷库 → 4. 库管员分级 → 5. 分级完成

### 赊销销售流程
1. 销售员创建赊销单 → 2. 客户信用额度校验 → 3. 账龄开始计算 → 4. 到期日预警 → 5. 回款催办 → 6. 回款确认

### 损耗处理流程
1. 库管员记录损耗 → 2. 提交审核 → 3. 经理审核 → 4. 确认/驳回 → 5. 库存调整

### 客诉处理流程
1. 销售员创建投诉 → 2. 上传凭证 → 3. 开始处理 → 4. 方案确认 → 5. 结案

## 常见问题

**Q: 数据会持久化吗？**
A: 当前版本数据存储在内存中，刷新页面会重置。生产环境需要接入后端API。

**Q: 如何修改演示数据？**
A: 编辑 `src/data/mockData.js` 文件即可修改演示数据。

**Q: 如何新增角色？**
A: 在 `src/data/constants.js` 中添加角色定义，并在 `ROLE_PERMISSIONS` 中配置权限。
