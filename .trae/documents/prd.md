## 1. 产品概述

礼品定制行业在打样确认、量产排期和售后补单之间反复拉扯，信息散落在报价单、样品照片和发货表中，拆单录完还得去别处补回执汇总，复盘时永远对不上。本系统建立一条完整的「发货拆单 → 回执汇总 → 回查追责」处理链，让一线处理和管理回看基于同一套数据运行。

- 解决核心问题：拆单发货漏件、确认版本被覆盖、退款处理缺责任链
- 目标用户：礼品定制公司的跟单员、仓管、财务、管理层

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 跟单员 | 选择角色进入 | 创建/编辑订单、发起拆单、录入回执、标记异常 |
| 仓管 | 选择角色进入 | 确认发货、填写物流单号、标记漏件 |
| 财务 | 选择角色进入 | 审核退款、关联责任链、确认回款 |
| 管理层 | 选择角色进入 | 查看仪表盘、回查面板、导出汇总 |

### 2.2 功能模块

1. **首页仪表盘**：待处理/已驳回/需回查数据总览，角色感知卡片
2. **订单管理**：订单列表、订单详情、版本历史与覆盖追踪
3. **发货拆单**：拆单操作、分批发货、漏件检测与告警
4. **回执汇总**：签收回执录入、异常标记、回执状态汇总
5. **回查面板**：连续回查时间线、责任链追溯、版本对比
6. **退款处理**：退款申请、责任链绑定、审批流程

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页仪表盘 | 数据总览 | 展示待处理、已驳回、需回查的订单/拆单/退款数量，按角色高亮当前待办 |
| 首页仪表盘 | 角色切换 | 顶部角色选择器，切换后仪表盘和操作权限实时变化 |
| 首页仪表盘 | 快捷入口 | 最近待办列表，点击直达对应处理页面 |
| 订单管理 | 订单列表 | 搜索/筛选/排序，状态标签（打样中/已确认/已拆单/已完成/已驳回） |
| 订单管理 | 订单详情 | 基本信息、版本历史时间线、当前确认版本高亮、覆盖预警 |
| 订单管理 | 版本覆盖追踪 | 当确认版本被修改时，记录覆盖人、时间、原因，标记为「需回查」 |
| 发货拆单 | 拆单操作 | 将订单按品类/工艺拆为多个子发货单，自动编号 |
| 发货拆单 | 分批发货 | 每批次的物流信息、发货状态、关联子单 |
| 发货拆单 | 漏件检测 | 拆单后自动核对原订单品项，遗漏项标红告警 |
| 回执汇总 | 回执录入 | 对每笔子发货单录入签收状态、签收人、异常说明 |
| 回执汇总 | 状态汇总 | 全部子单的回执状态一览，未回执/已签收/异常标记 |
| 回查面板 | 连续回查时间线 | 按订单聚合所有操作事件（拆单/发货/回执/版本覆盖/退款），时间线展示 |
| 回查面板 | 责任链追溯 | 每个异常节点可展开查看操作人、审批人、关联记录 |
| 回查面板 | 版本对比 | 选择两个版本对比差异，高亮变更字段 |
| 退款处理 | 退款申请 | 关联原始订单和子发货单，填写退款原因和金额 |
| 退款处理 | 责任链绑定 | 退款必须绑定责任环节（跟单遗漏/仓管错发/物流损坏），不可跳过 |
| 退款处理 | 审批流程 | 财务审核 → 管理层确认，审批意见留痕 |

## 3. 核心流程

**主流程：订单创建 → 打样确认 → 量产排期 → 发货拆单 → 回执汇总 → 异常回查/退款**

1. 跟单员创建订单，上传打样确认版本
2. 确认版本可被覆盖，但每次覆盖自动生成「版本覆盖记录」并触发「需回查」标记
3. 仓管根据订单进行拆单操作，系统自动检测漏件
4. 分批发货后，签收回执逐笔录入
5. 回执异常或漏件触发回查面板告警
6. 退款必须关联责任链，财务和管理层逐级审批

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深炭灰 (#1a1a2e) + 琥珀橙 (#e8a838) 强调色，传达专业与紧迫感
- 辅助色：冷灰蓝 (#4a5568) 用于次要信息，柔绿 (#48bb78) 用于完成状态，珊瑚红 (#fc5c65) 用于异常/驳回
- 按钮风格：圆角6px，主按钮实心琥珀橙，次按钮描边，危险操作珊瑚红
- 字体：中文使用思源黑体（Noto Sans SC），数字/英文使用 DM Mono 等宽字体，强调数据感
- 布局：左侧导航 + 右侧内容区，卡片式模块，表格为主的数据展示
- 图标：线性图标，2px描边，统一风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页仪表盘 | 数据总览 | 三列统计卡片（待处理/已驳回/需回查），数字用大号DM Mono，卡片底部微型趋势条 |
| 首页仪表盘 | 角色切换 | 顶部右侧角色下拉选择器，切换带微动效，当前角色对应待办高亮 |
| 首页仪表盘 | 快捷入口 | 紧凑型待办列表，每行显示订单号+状态标签+操作人，点击跳转 |
| 订单管理 | 订单列表 | 表格布局，状态标签色彩区分，行hover展开快捷操作 |
| 订单管理 | 订单详情 | 上方信息卡片 + 下方版本时间线（竖向），覆盖节点标红 |
| 发货拆单 | 拆单操作 | 左侧原始订单品项 + 右侧拆分结果，拖拽或点击分配 |
| 发货拆单 | 漏件检测 | 漏件项以珊瑚红边框卡片弹出，带声音/视觉告警 |
| 回执汇总 | 回执录入 | 侧滑面板，从右滑入填写签收信息 |
| 回查面板 | 时间线 | 竖向时间线，节点可展开详情，异常节点放大+红色边框 |
| 退款处理 | 退款表单 | 步骤式表单，责任链为必填下拉选择 |

### 4.3 响应式策略

- 桌面优先设计，最小宽度 1024px
- 1280px 以下侧边栏收缩为图标模式
- 表格列在窄屏下可折叠次要列

### 4.4 空态与错误态

- **空态**：使用插画+引导文案，如「暂无待处理订单，喝杯咖啡吧」+「创建第一个订单」按钮
- **错误态**：顶部红色横幅提示错误信息，提供重试按钮，保留已填写数据
- **加载态**：骨架屏替代 loading 圈，保持布局稳定
- **权限态**：角色无权限操作时，按钮置灰并tooltip提示「当前角色无此权限」
