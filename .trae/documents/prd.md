## 1. 产品概述
农机合作社作业预约与机手排班协作平台。用统一的信息链路替代电话、作业表和油料本的分散记录，让理事、调度员、机手按角色接力处理。
- 目标：让作业预约、机手排班、油料/补贴材料、维修/回访异常都能在同一系统留痕可查。
- 价值：减少"各记各的账"，把每一步确认、修改、处理人落到页面上。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 合作社理事 | 预置账号 | 查看全部作业、异常统计、审批补贴材料、对外回复 |
| 调度员 | 预置账号 | 新建/调整作业预约、分配机手与机具、登记油料出库 |
| 机手 | 预置账号 | 领取/确认任务、报地块进度、上报维修与回访异常 |

### 2.2 功能模块
1. **首页概览**：待处理卡片、异常汇总、当日排班、近 7 天趋势。
2. **作业预约**：按地块登记预约（作物/面积/农机类型/期望时间）、列表筛选、快速改派。
3. **机手排班**：时间轴看板、任务分配、冲突检测、空闲机手推荐。
4. **异常处理抽屉**：地块进度报晚、补贴材料不齐、维修上报、客户回访四类异常的处理与留痕。
5. **角色切换器**：一键切换理事/调度/机手视角，便于联调演示。

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页概览 | 异常计数卡 | 红黄绿三色状态卡，点击跳转对应列表 |
| 首页概览 | 今日排班时间轴 | 按时段显示机手任务，冲突以红底标注 |
| 首页概览 | 待确认列表 | 展示待机手/调度确认的任务，支持一键确认 |
| 作业预约 | 预约登记表单 | 地块、作物、面积、农机、期望时段、备注 |
| 作业预约 | 预约列表 | 按状态筛选（待派/已派/作业中/完成/异常），支持搜索、改派 |
| 机手排班 | 排班看板 | 机手 × 时段的二维看板，拖拽/按钮调整分配 |
| 机手排班 | 空闲推荐 | 根据农机类型、距离、上一个任务结束时间推荐 |
| 异常抽屉 | 分类标签 | 进度/补贴/维修/回访 四类异常 |
| 异常抽屉 | 时间线留痕 | 每次上报、处理、确认都记录人和时间 |
| 异常抽屉 | 处理动作 | 改派、退回、确认、归档，并可加备注 |

## 3. 核心流程
调度员收到客户电话后在"作业预约"录入地块作业 → 系统根据机手与机具状态给出推荐 → 调度员确认排班 → 机手在"今日任务"中领取并按时作业 → 机手在作业后上报地块进度/补贴材料/维修/回访 → 异常在抽屉中按时间线留痕，调度或理事处理后闭环。

## 4. 用户界面设计

### 4.1 设计风格
- 主色：深青蓝 `#0F3A4A`，辅色：暖琥珀 `#E8A53C`，中性：`#1B2A33 / #EAEAEA`。
- 圆角：卡片 14px，按钮 10px，输入 8px。
- 字体：标题用「思源黑体 Heavy」，正文用「PingFang SC / Inter」。
- 布局：顶部导航 + 左侧菜单 + 主工作区，卡片式信息块。
- 图标：Lucide（lineicons）。
- 整体调性：硬朗工业感 + 暖色点缀，避免花哨渐变。

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页 | 异常计数卡 | 大数字 + 状态徽标 + 点击跳转 |
| 首页 | 今日时间轴 | 横向时段条，机手纵向排列 |
| 作业列表 | 行操作 | hover 显示改派/查看详情按钮 |
| 异常抽屉 | 时间线 | 竖线节点 + 头像 + 时间戳 |
| 异常抽屉 | 动作区 | 底部粘底操作栏（改派/确认/归档） |

### 4.3 响应式
桌面优先（1280px+），最小支持 1024px；抽屉面板在窄屏自动变为全屏。

## 5. 数据模型（简要）
- 机手：id/name/phone/machineType/status/avatar
- 地块：id/name/area/crop/location
- 作业预约：id/plotId/crop/area/machineType/expectedAt/operatorId/status/timeline
- 异常事件：id/taskId/type/severity/reporterId/handlerId/timeline/resolved
- 油料与补贴：与作业预约关联，记录出库、材料、审批人

## 6. 刻意简化
- 无后端、无真实鉴权：角色切换仅用于演示不同视角，所有数据用 mock。
- 无真正的地理位置计算：空闲推荐仅基于固定距离字段。
- 无文件上传：补贴材料以模拟附件列表替代。
