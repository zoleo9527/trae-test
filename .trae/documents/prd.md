## 1. 产品概述

礼品定制行业的打样确认与量产排期管理平台。解决当前靠报价单、样品照片和发货表拼接工作的问题，将打样确认、量产排期、售后补单的全流程动作沉淀到页面内，消除依赖记忆补位的风险，确保确认版本可追溯、拆单发货不漏件、退款处理有责任链。

- 目标用户：礼品定制企业的项目商务、打样跟单、仓配协调三类角色
- 核心价值：将散落在聊天工具和表格中的确认-排期-发货流程收拢为一条可留痕、可回查的流水线

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 项目商务 | 管理员分配账号 | 查看全部订单推进状态、总览看板、发起退款审批 |
| 打样跟单 | 管理员分配账号 | 打样确认全流程操作、版本对比、发起异常标记 |
| 仓配协调 | 管理员分配账号 | 量产排期操作、发货管理、异常回查与处理 |

### 2.2 功能模块

1. **工作台总览页**：角色适配看板、异常预警卡片、待办事项队列
2. **订单详情页**：打样确认+量产排期双轨视图、版本时间线、操作日志
3. **异常处理页**（抽屉式）：版本覆盖告警、拆单漏件检测、退款责任链

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台总览 | 角色看板 | 根据登录角色展示不同的统计卡片：商务看推进率、跟单看打样阶段分布、仓配看排期与异常数 |
| 工作台总览 | 异常预警 | 红色/橙色标记的异常订单列表，点击直接跳转对应异常处理抽屉 |
| 工作台总览 | 待办队列 | 当前角色的待确认、待排期、待发货、待处理异常的快捷入口 |
| 订单详情 | 双轨视图 | 上半区打样确认流程（报价→寄样→客户确认→版本锁定），下半区量产排期流程（排期→生产→质检→发货） |
| 订单详情 | 版本时间线 | 样品确认版本的可视化时间线，每次确认变更留痕，支持两版本对比 |
| 订单详情 | 操作日志 | 不可编辑的操作记录流，记录每步操作人、时间、变更内容 |
| 异常处理抽屉 | 版本覆盖告警 | 当确认版本被回退或覆盖时触发，展示新旧版本差异，要求填写覆盖原因 |
| 异常处理抽屉 | 拆单漏件检测 | 拆单发货时自动比对明细，发现漏件自动标记，支持补发工单生成 |
| 异常处理抽屉 | 退款责任链 | 退款申请必须填写责任方（工厂/客户/物流/内部），逐级审批并留痕 |

## 3. 核心流程

**主流程**：客户提出需求 → 商务创建报价 → 跟单安排打样 → 样品寄出 → 客户确认（可能多轮）→ 版本锁定 → 仓配安排量产排期 → 生产质检 → 拆单发货 → 售后补单（如有）

**异常触发点**：
- 客户在版本锁定后要求修改 → 触发版本覆盖告警
- 拆单发货明细与订单不匹配 → 触发漏件检测
- 退款申请缺少责任方 → 触发责任链补全

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝(#1e293b)作为侧边栏和头部，搭配琥珀橙(#f59e0b)作为异常/警示色
- 辅助色：翡翠绿(#10b981)表示完成/通过，石板灰(#64748b)表示待处理
- 按钮风格：圆角(8px)、适度阴影，主要操作用实色填充，次要操作用描边
- 字体：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- 布局风格：左侧固定导航栏 + 顶部面包屑 + 主内容区卡片式布局
- 图标风格：线性图标(Lucide)，统一2px描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 工作台总览 | 角色看板 | 四宫格统计卡片，数字大号加粗，底部微趋势线 |
| 工作台总览 | 异常预警 | 带左侧色条的列表行，红/橙色条表示严重程度 |
| 工作台总览 | 待办队列 | 可勾选的任务列表，带状态徽章 |
| 订单详情 | 双轨视图 | 上下两段式布局，每段为步骤条+卡片组合 |
| 订单详情 | 版本时间线 | 垂直时间线，节点为版本号，连线为变更说明 |
| 订单详情 | 操作日志 | 紧凑的日志流，灰色小字时间戳+操作人头像 |
| 异常处理抽屉 | 版本覆盖告警 | 对比视图：左右两列展示新旧版本，差异高亮 |
| 异常处理抽屉 | 拆单漏件检测 | 表格形式，漏件行红底高亮，补发按钮在行尾 |
| 异常处理抽屉 | 退款责任链 | 步骤式审批流，每个节点显示审批人和结果 |

### 4.3 响应式策略

桌面优先设计，主内容区最小宽度1024px，侧边栏可折叠。不单独适配移动端。

### 4.4 动效指引

- 页面切换：淡入 + 轻微上移(translateY: 8px → 0)，200ms
- 卡片悬停：阴影加深 + 轻微上浮(translateY: -2px)
- 异常预警闪烁：琥珀橙低频脉冲(2s周期)
- 抽屉滑入：从右侧滑入，300ms ease-out
- 版本对比差异高亮：黄色背景渐显，500ms
