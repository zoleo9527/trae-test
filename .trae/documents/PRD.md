## 1. 产品概述

洗涤工厂门店交接与回单核验协作系统——解决收衣单、返洗记录与交接回单散落各处的管理断层问题，让厂长、质检员、门店交接员在同一处理面上各司其职，消除污损争议、批次混洗和赔付扯皮。

- 目标用户：中小型洗涤工厂的厂长、质检员、门店交接员
- 核心价值：将"收衣→分拣→洗涤→质检→门店交接→回单核验"全流程闭环，每一步有据可查，超时自动预警，退回有证据链

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 厂长 | 角色切换选择「厂长」 | 全局看板、分拣指派、超时监控、赔付审批、批次追踪 |
| 质检员 | 角色切换选择「质检员」 | 质检登记、返洗判定、污损拍照记录、质检报告 |
| 门店交接 | 角色切换选择「门店交接」 | 交接确认、回单核验、退回登记、回查标记 |

### 2.2 功能模块

1. **首页仪表盘**：待处理 / 已驳回 / 需回查数据一览，超时预警，今日待办
2. **订单流水线**：收衣→分拣→洗涤→质检→门店交接→回单核验全流程跟踪
3. **侧边处理台**：快速处理当前任务，无需跳转页面
4. **污损证据链**：拍照记录 + 位置标注 + 时间戳，不可篡改
5. **批次追踪**：混洗批次管理，单件可溯源至批次
6. **返洗管理**：返洗原因记录、返洗流程跟踪、返洗后复检

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 3. 核心流程

**门店交接与回单核验主流程**：门店送衣→工厂收衣登记→分拣（厂长指派）→按批次洗涤→质检（质检员检查）→合格则门店交接→门店核验签收→回单完成；不合格则标记返洗/污损→返洗流程→复检→再交接。

    "污损记录+拍照" --> "赔付判定(厂长)"

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青灰 (#1B2B3A) + 琥珀强调色 (#F59E0B)，工业感与警示性兼具
- **次色调**：石板灰 (#475569) 用于背景层级，翡翠绿 (#10B981) 用于完成状态，珊瑚红 (#EF4444) 用于超时/驳回
- **按钮风格**：圆角微弧（6px），主要操作用实色填充，次要操作用描边
- **字体**：Noto Sans SC 作为主体字体，JetBrains Mono 用于编号/数据
- **布局风格**：左侧固定导航 + 中间看板/列表 + 右侧滑出处理台
- **图标风格**：线性描边图标（Lucide Icons）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页仪表盘 | 数据概览卡片 | 4列网格卡片，数字大字号+标签小字号，琥珀/绿/红/灰色区分状态 |
| 首页仪表盘 | 超时预警条 | 红色渐变条带，闪烁脉冲动画，显示超时订单号和停留时长 |
| 首页仪表盘 | 今日待办列表 | 左侧时间轴，右侧任务卡片，按角色过滤标签 |
| 订单流水线 | 看板视图 | 六列水平滚动看板，列头带状态色条，卡片可点击打开侧边处理台 |
| 侧边处理台 | 滑出面板 | 右侧400px滑出，表单+操作按钮，底部固定操作栏 |
| 侧边处理台 | 污损拍照 | 上传区域+预览缩略图+位置下拉+描述文本框 |
| 批次追踪 | 批次详情 | 左侧批次列表，右侧详情面板，衣物编码高亮可点击 |

### 4.3 响应式设计

- 桌面优先（1920/1440/1280 三档）
- 1280 以下侧边处理台改为全屏模态
- 触控优化：卡片点击区域 ≥ 44px，按钮间距 ≥ 12px

### 4.4 动效设计

- 页面加载：卡片依次淡入上滑（stagger 50ms）
- 侧边处理台：从右侧滑入，背景遮罩渐现
- 超时预警：脉冲呼吸动画
- 状态变更：卡片左边缘色条过渡动画
- 交接确认：全宽绿色进度条从左到右填充
