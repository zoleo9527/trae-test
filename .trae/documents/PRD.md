# 水果批发客诉赔付与复检登记系统 - 产品需求文档

## 1. 产品概述

本系统为水果批发行业提供客诉赔付与复检登记一体化解决方案，解决当前流程分散、损耗说不清、赔付无证据、回款滞后等核心问题。通过统一的批量复核工作面，实现档口负责人、配货员、财务记账三类角色的协同作业。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 档口负责人 | 现场管理，处理客诉与复检 | 完整操作权限：登记客诉、发起复检、审批赔付、批量复核 |
| 配货员 | 执行配货和复检操作 | 登记复检信息、上传证据、更新状态、查看分配任务 |
| 财务记账 | 回款管理与结算 | 查看赔付记录、登记回款、生成报表、财务数据统计 |

### 2.2 功能模块

1. **批量复核面板**：核心工作区，集中展示待处理客诉与复检任务，支持批量操作
2. **客诉登记**：客诉信息录入、关联过磅单、上传证据图片
3. **复检登记**：复检流程记录、冷库表关联、分级判定、损耗计算
4. **赔付审批**：赔付金额核算、多级审批、状态流转
5. **回款跟踪**：回款登记、逾期提醒、结算对账
6. **历史追溯**：完整操作日志、状态变更记录、责任人追踪

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|

| 批量复核面板 | 快速操作区 | 一键通过、驳回、转复检、登记赔付等快捷操作 |

## 3. 核心流程

```mermaid
flowchart LR
    A["客诉登记"] --> B["关联过磅单/冷库表"]
    B --> C["发起复检"]
    C --> D["复检登记<br/>(分级判定+损耗计算)"]
    D --> E{"是否赔付?"}
    E -->|是| F["赔付核算"]
    E -->|否| G["结案归档"]
    F --> H["赔付审批"]
    H --> I["财务回款登记"]
    I --> G
```

**流程说明：**
1. 客诉发生时，档口负责人在系统中登记客诉信息，关联对应过磅单和客户信息
2. 客诉登记后自动进入复检流程，配货员执行复检并录入复检结果（分级、损耗）
3. 系统根据复检结果自动计算损耗金额，档口负责人判定是否赔付
4. 需要赔付的案件进入赔付审批流程，财务确认后登记回款
5. 所有状态变更、操作人、时间点、备注均完整记录，支持完整追溯

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色(#0F4C5C) - 专业、稳重，适合企业级系统
- **辅助色**：橙红色(#E36414) - 强调、警告，用于客诉标记
- **成功色**：青绿色(#2A9D8F) - 通过、完成状态
- **警示色**：琥珀色(#F4A261) - 待处理、进行中
- **中性色**：深灰(#264653)、中灰(#6B7280)、浅灰(#F3F4F6)

- **按钮风格**：圆角6px，悬停微上浮效果，点击反馈
- **字体**：Inter - 现代无衬线字体，清晰易读
- **布局风格**：卡片式布局，左侧导航+主工作区+右侧详情三栏结构
- **图标风格**：线性图标，统一24px尺寸

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 批量复核面板 | 顶部筛选栏 | 状态筛选、时间范围、客户搜索、快速搜索框 |
| 批量复核面板 | 任务卡片列表 | 卡片包含：客户名、客诉类型、当前状态、操作时间、责任人、快捷操作按钮 |
| 批量复核面板 | 批量操作栏 | 选中计数、批量通过、批量转复检、批量导出 |
| 批量复核面板 | 详情侧滑 | 从右侧滑出，展示完整信息、操作历史、时间线 |
| 客诉/复检表单 | 表单区域 | 分组布局，必填项标记，实时校验 |
| 客诉/复检表单 | 证据上传 | 拖拽上传，缩略图预览，删除功能 |
| 历史记录页 | 时间线 | 垂直时间线，状态节点高亮，操作人头像 |

### 4.3 响应式

- 桌面端优先设计，最小支持1280px宽度
- 三栏布局在小屏幕下自动折叠为两栏或单栏
- 侧滑详情在平板端转为全屏覆盖
- 触摸设备优化按钮尺寸和点击区域

## 5. 非功能性需求

### 5.1 性能要求
- 列表加载时间 < 2秒（500条数据）
- 表单提交响应 < 500ms
- 图片上传支持断点续传

### 5.2 数据完整性
- 所有操作留痕，不可删除只能标记作废
- 状态流转必须记录操作人和时间
- 证据文件关联不可删除

### 5.3 边界处理（轻量实现）
- 暂不实现复杂的权限细粒度控制，采用角色级权限
- 暂不实现消息推送，采用页面轮询刷新
- 暂不实现复杂报表，基础统计展示即可
- 暂不实现多级审批，档口负责人直接审批
