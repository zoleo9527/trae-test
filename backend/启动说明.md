# 《地方剧院-设备借用与场次复盘》后端服务

## 🚀 快速启动

### 1. 环境要求
- Node.js >= 18.x
- npm >= 9.x

### 2. 安装依赖
```bash
cd backend
npm install
```

### 3. 数据库初始化
```bash
# 执行数据库迁移
npm run db:init

# 填充演示数据
npm run db:seed
```

### 4. 启动服务
```bash
# 开发模式（自动重启）
npm run dev

# 生产模式
npm start
```

### 5. 访问地址
- API 基础地址: `http://localhost:3001/api/v1`
- 健康检查: `http://localhost:3001/api/v1/health`

## 🔄 角色切换方式

### 方式一：登录时指定角色
登录接口必须传入 `role` 参数，以该角色身份获取 Token：

```bash
curl -X POST http://localhost:3001/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "manager",
    "password": "password123",
    "role": "THEATER_MANAGER"
  }'
```

### 方式二：已登录后切换角色
使用当前 Token 调用切换角色接口：

```bash
curl -X POST http://localhost:3001/api/v1/auth/switch-role \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <your-token>" \
  -d '{
    "role": "TICKET_SUPERVISOR"
  }'
```

## 🔐 安全与幂等性

### 请求头说明
所有需要认证的接口必须携带：
```
Authorization: Bearer <your-token>
```

### 幂等性支持
对于创建、审批等关键操作，可通过 `x-idempotency-key` 请求头保证幂等：
```
x-idempotency-key: <unique-request-key>
```
相同的幂等键在 24 小时内重复请求会直接返回首次响应。

## ⚠️ 当前版本边界说明（轻量实现）

### 已实现 ✅
1. **完整的 RBAC 权限体系** - 三角色权限边界清晰
2. **全链路审计追踪** - 所有关键操作记录前后值、操作人、时间戳
3. **状态机流转** - 排期、借用、团单均有严格的状态流转规则
4. **接口幂等性** - 通过请求头支持防重复提交
5. **多态备注系统** - 所有业务实体均可附加备注和补录说明
6. **异常处理** - 驳回操作强制要求填写原因
7. **演示数据** - 包含完整业务链路的测试数据
8. **统一响应格式** - 前端可预期的标准化响应

### 待实现 / 轻量处理 ⚡
1. **实时通知** - 暂未实现 WebSocket 推送，状态变更依赖前端轮询
2. **文件上传** - 暂未实现附件上传，备注仅支持文本
3. **复杂报表** - 暂未实现多维度统计报表，仅提供基础列表查询
4. **移动端适配** - API 设计支持但未做专门优化
5. **消息中心** - 站内信、邮件通知等暂未实现
6. **数据导出** - Excel/PDF 导出功能暂未实现
7. **多剧院支持** - 当前为单剧院设计，未做多租户隔离
8. **定时任务** - 设备逾期自动标记、自动提醒等暂未实现
9. **复杂工作流** - 当前为线性审批，暂不支持会签、或签等复杂流程
10. **数据备份** - 数据库备份策略需运维自行配置
