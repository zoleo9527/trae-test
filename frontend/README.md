# 洗涤工厂 - 月结对账与客诉赔付系统

## 项目概述

这是一个专为洗涤工厂设计的管理系统，解决月结对账与客诉赔付两个核心痛点。系统采用 **Vue 3 + Vite + TypeScript** 技术栈，通过统一工作台实现订单、批次、客诉、对账的全流程管理。

## 核心特性

### 🎯 解决的核心问题
1. **污损争议没证据** - 每件衣物都记录瑕疵照片和备注，争议可追溯
2. **批次混洗难追** - 批次与订单关联，每一件衣服都能查到在哪个批次洗涤
3. **赔付靠口头解释** - 客诉全流程记录，举证照片、处理意见、赔付金额一目了然

### 📊 主要功能模块
1. **工作台** - 统计概览 + 批量复核面板（核心）
2. **订单管理** - 收衣单全生命周期管理
3. **批次追踪** - 洗涤批次管理与混洗追溯
4. **客诉赔付** - 客诉登记、调查、审批、赔付全流程
5. **月结对账** - 按门店按月对账，双方确认签字

## 角色切换说明

系统支持三种角色，不同角色有不同的操作权限：

### 🏭 厂长 (factory_manager)
- 查看所有数据和进度
- 审批客诉赔付（同意/拒绝赔付）
- 月结对账 - 工厂确认签字

### 🔍 质检员 (quality_inspector)
- 批量分拣、质检操作
- 处理返洗订单
- 发起客诉调查

### 🏪 门店经理 (store_manager)
- 查看门店订单状态
- 交接回单确认
- 月结对账 - 门店确认签字

**切换方式**：点击右上角用户名，在下拉菜单中选择切换角色。

## 核心功能演示

### 1. 批量复核面板（工作台）
- 全选/单选订单进行批量操作
- 支持批量分拣、批量质检通过、批量返洗
- 右侧面板实时查看订单详情或操作历史
- 搜索和状态筛选快速定位订单

### 2. 批次追踪
- 查看进行中和已完成的洗涤批次
- 点击批次卡片查看关联的订单和衣物
- 查看每件衣物的瑕疵记录和照片

### 3. 客诉赔付处理
- 客诉列表展示所有争议订单
- 客诉详情包含：问题描述、举证照片、客户要求赔付、核定赔付
- 只有厂长有权限进行赔付审批
- 处理流程：待处理 → 调查中 → 同意赔付/拒绝赔付

### 4. 月结对账
- 按门店展示月度对账汇总
- 显示订单数、衣物数、洗涤收入、赔付金额、净结算
- 双方确认机制：厂长确认 + 门店经理确认 = 对账完成

## 技术栈

- **框架**: Vue 3.4 + TypeScript
- **构建工具**: Vite 5
- **状态管理**: Pinia (含持久化插件)
- **路由**: Vue Router 4
- **UI 组件**: Element Plus
- **样式**: Tailwind CSS
- **日期处理**: Day.js

## 使用建议

1. **首次体验**：从【工作台】开始，尝试批量选择订单并执行批量操作
2. **查看链路**：进入【订单管理】点击任意订单，查看完整的状态流转历史
3. **角色体验**：切换不同角色，体验各角色的权限差异
4. **客诉处理**：进入【客诉赔付】，切换到厂长角色进行赔付审批
5. **对账流程**：进入【月结对账】，分别用厂长和门店经理角色完成双方确认
