# 婚纱影楼 · 档期与选片协同台

把「档期预约 / 选片确认 / 尾款催收 / 异常处理」串成一条可来回追踪的链，避免改期漏改、修片版本混乱、客诉时翻聊天。

## 技术栈

- 前端：SvelteKit + TypeScript + 原生 CSS
- 后端：Go 1.22 + Fiber v2（内存数据源，重启即还原）
- 前后端边界：前端只做状态与交互，业务动作统一通过 `/api/*` 完成；时间线/留痕由后端在每次写操作时自动追加。

## 启动方式

### 1) 后端

```bash
cd server
go mod tidy
go run ./cmd
```

监听：`http://localhost:8787`

### 2) 前端

```bash
cd client
npm install
npm run dev
```

访问：`http://localhost:5173`

> 构建前端：`npm run build`（需先 `npm install` 安装依赖）

## 刻意简化的部分

1. **存储为内存**：每次重启后端演示数据复原；真实场景建议 PostgreSQL + `orders / slots / selections / payments / exceptions / timeline_events` 表结构。
2. **鉴权为 Token 头 + 内存会话**：真实场景可替换为 JWT + Refresh。
3. **无真正的图片上传**：`photos` 字段仅存照片编号字符串。
4. **异常严重度只有高中低三档**：真实业务可按流程模板沉淀（改期漏改、修片版本混乱、尾款催收、客诉、其他）。
5. **未做通知推送、消息中心**：当前以时间线代替，后续可接企业微信 / 钉钉 / 短信。
6. **无 RBAC 细粒度**：三种角色共用订单数据，仅在视图/入口上做区分；真实环境可加按订单分配负责人 + 操作审计。
