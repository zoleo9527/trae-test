# 家具展厅-订单配置与到货跟踪

完整订单配置、到货跟踪、安装预约、样品借出、补件确认处理链系统。

## 系统架构

- **后端**: FastAPI + SQLAlchemy + SQLite
- **前端**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **核心链路**: 订单 → 定制配置 → 到货跟踪 → 安装预约 → 样品借出 → 补件确认 → 售后处理

## 快速启动

### 1. 启动后端

```bash
cd server
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

后端 API 文档: http://localhost:8000/docs

### 2. 启动前端

```bash
cd client
npm install
npm run dev
```

前端访问: http://localhost:3000

## 核心功能模块

### 1. 订单管理
- 订单创建、编辑、状态流转
- 商品清单管理（增删改）
- 客户信息、金额、预计交付日期

### 2. 定制配置
- 配置类型：颜色/材质/尺寸/内部结构/五金/灯光等
- 配置项关联到具体商品或全局
- 待确认/已确认状态管理
- 配置变更自动记录时间线

### 3. 到货跟踪
- 到货登记（关联商品、物流单号、库位）
- 异常标记：**部分到货**、**损坏数量**、**缺失数量**
- 异常自动触发时间线事件

### 4. 安装预约
- 预约创建（安装师、联系人、时间）
- 状态流转：已预约→已确认→已完成/有问题/已取消
- **改期计数**（记录改期次数）
- 问题描述字段

### 5. 样品借出
- 借出登记（样品、借用人、应还日期）
- 归还确认（状态、完好程度）
- **超期自动标记**
- 丢失处理

### 6. 补件确认
- 补件申请（关联商品、原因、数量）
- 状态流转：待处理→已下单→已到货→已安装→已确认
- 全流程时间线记录

### 7. 连续回查面板（右侧栏）
- 实时汇总：超期样品、未还样品、到货损坏、到货缺失、待处理补件
- **异常项数字徽章**
- 最近操作快速浏览

### 8. 处理链路时间线
- **全流程可视化**：所有操作自动记录
- 按时间倒序展示
- 事件类型图标化
- 操作人记录

## 刻意简化的部分

以下功能在本演示中做了简化，实际生产环境需要补充：

1. **认证鉴权**: 当前为简单用户名密码比对，无 JWT Token 验证，无权限中间件
2. **文件上传**: 到货拍照、配置确认单等需要上传图片，暂未实现
3. **消息通知**: 样品超期提醒、安装预约确认短信/微信推送等未实现
4. **数据审计**: 操作日志、数据变更历史暂简化为时间线
5. **多仓库/多门店**: 当前假设单仓库单展厅
6. **供应商管理**: 到货追踪中的供应商信息简化为物流单号
7. **财务结算**: 定金/尾款的支付记录、发票管理暂未涉及
8. **客户评价**: 安装完成后的满意度评价暂未实现
9. **数据导出**: Excel/PDF 导出功能暂未实现
10. **移动端适配**: 界面为桌面端优化，移动端体验需要调整
