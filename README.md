# 农机合作社 · 作业预约与机手排班协作平台

用统一的信息链路替代电话、作业表和油料本的分散记录，让理事、调度员、机手按角色接力处理。作业谁改过、谁确认过、谁还没处理，都在同一页能看到；地块进度、补贴材料、维修和回访的异常，不再靠聊天工具补说明。

## 技术栈

- **前端**：Vue 3 + TypeScript + Vite 5
- **状态管理**：Pinia
- **路由**：Vue Router 4
- **样式**：Tailwind CSS 3
- **图标**：lucide-vue-next
- **后端**：无（纯前端演示，数据在 `src/mock/` 内）

### 异常处理抽屉

四类异常统一在右侧抽屉内处理：**地块进度 / 补贴材料 / 维修 / 客户回访**。

- 点击任意异常行的"处理"按钮或任务行上的"异常"标记打开抽屉
- 抽屉内可按类别关键词筛选时间线，查看同任务的其他异常
- 支持快捷动作（确认进度追平、通知村委会补材料、确认配件到位等）
- 支持退回、改派、通知理事、处理完成并归档
- 所有操作写入时间线，可一键复制为补贴与维修留痕依据

## 刻意简化的部分

- **无后端、无真实鉴权**：角色切换仅用于演示不同视角，所有数据用 mock
- **无持久化**：所有数据在前端内存中，刷新即重置
- **无地理位置计算**：空闲推荐仅基于固定距离字段和机手状态排序
- **无文件上传**：补贴材料与维修记录以模拟附件列表替代
- **时间冲突判断仅基于当日时间段**，不考虑跨日
- **无通知推送、无短信、无地图**
- **无油料出库登记的独立模块**（油料记录在任务时间线内以备注形式体现）
