# 废品回收站-车辆过磅与结算复核系统

基于 Electron + Vue 3 + SQLite 的桌面端废品回收站管理系统

## 功能特性

### 核心业务流程
- **车辆过磅**: 支持车牌自动识别、车辆信息自动填充、净重自动计算、磅单打印
- **结算复核**: 批量选择过磅单结算、多级审批流程（财务结算 -> 站长复核 -> 付款）
- **追踪溯源**: 通过磅单号或结算单号追踪完整业务流程和操作历史

### 角色权限
- **站长(owner)**: 全部权限，包括价格调整、复核结算、查看日志
- **过磅员(weigher)**: 过磅登记、车辆管理、磅单打印
- **财务(accountant)**: 结算处理、异常处理、导出报表

### 系统特点
1. **本地 SQLite 数据库**: 数据安全，无需网络
2. **操作日志完整**: 所有改动均可回溯
3. **异常自动检测**: 价格偏离自动标记异常
4. **环保台账**: 满足监管要求
5. **批量处理**: 支持批量打印、批量结算
6. **打印功能**: 标准格式磅单、结算单打印

## 启动方式

### 开发环境

1. 安装依赖
```bash
npm install
```

2. 启动开发服务
```bash
npm run dev
```

3. 启动 Electron（新开终端）
```bash
VITE_DEV_SERVER_URL=http://localhost:5173 npx electron .
```

或者一键启动：
```bash
npm run electron:dev
```

### 生成演示数据

首次启动后，可运行脚本生成演示数据：

```bash
node scripts/init-demo-data.js
```

## 技术栈

- **前端**: Vue 3 + Element Plus + Pinia + Vue Router
- **桌面端**: Electron
- **数据库**: SQLite (better-sqlite3)
- **工具库**: dayjs (日期) + xlsx (导出)

## 数据库位置

- Mac: `~/Library/Application Support/scrap-station-manager/scrap-station.db`
- Windows: `%APPDATA%/scrap-station-manager/scrap-station.db`

## 刻意简化的部分

1. **密码加密**: 演示版本使用明文存储，生产环境应使用 bcrypt 等加密
2. **图片上传**: 堆场照片功能简化，仅保留字段
3. **磅秤对接**: 未连接实际磅秤硬件，手动输入重量
4. **网络同步**: 纯本地版本，未实现多站点数据同步
5. **扫码功能**: 未实现二维码/条形码扫描
6. **消息通知**: 未实现站内消息推送
7. **数据备份**: 需手动备份数据库文件
8. **权限粒度**: 角色权限较粗，未实现细粒度权限控制
