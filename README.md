# 洗涤工厂管理系统 - 收衣分拣与污损复判

## 项目概述

这是一个基于 Electron + React + SQLite 的桌面端洗涤工厂管理系统，核心解决「收衣分拣与污损复判」完整处理链路问题，实现厂长、质检员、门店交接在同一条链路中接力，一线处理和管理回看基于同一套数据。

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite
- **桌面框架**: Electron
- **UI组件**: Ant Design
- **本地数据库**: SQLite (better-sqlite3)
- **数据持久化**: electron-store
- **Excel导入**: xlsx

## 启动方式

### 1. 安装依赖

```bash
npm install
```

### 2. 开发模式运行

```bash
npm run dev
```

该命令会同时启动 Vite 开发服务器和 Electron 客户端。

### 3. 打包生产版本

```bash
npm run build
```

## 核心功能模块

### 1. 工作台 (Dashboard)
- 今日批次统计
- 待处理批次一览
- 待复判污损记录
- 快速入口导航

### 2. 批次管理 (Batch)
- 新建批次
- 批次列表查看
- 批次详情（衣物清单）
- 单条添加衣物
- Excel批量导入衣物
- 操作日志追踪

### 3. 收衣分拣 (Sorting)
- 扫码/编号录入衣物
- 本地缓存恢复（刷新不丢失）
- 分拣状态流转
- 一键上报污损
- 已扫描衣物列表

### 4. 污损复判 (Damage)
- 污损记录列表
- 按状态筛选（待处理/已确认/已退回）
- 污损详情查看
- 厂长复判决策：
  - 确认洗涤（工厂承担风险）
  - 退回门店（不洗涤）
- 赔付金额记录
- 复判意见留存

### 5. 衣物查询 (Search)
- 多关键词搜索（编号/姓名/电话）
- 衣物完整信息展示
- 操作日志时间线
- 全链路追踪

## 刻意简化的部分

1. **用户管理**
   - 仅内置3个测试账号，未实现用户增删改
   - 密码明文存储（生产环境需加密）

2. **照片证据**
   - UI预留了证据照片字段，但未实现相机调用和文件上传
   - 可后续集成 WebRTC 或调用系统文件选择器

3. **打印功能**
   - 未实现标签打印、回单打印
   - 可集成 electron-printer 或调用系统打印

4. **网络同步**
   - 纯本地SQLite，未实现云端同步
   - 可后续增加轻量HTTP服务实现多端同步

5. **短信/通知**
   - 未实现客户短信通知
   - 可集成阿里云短信等服务

6. **财务模块**
   - 赔付金额仅记录，未对接实际收付款
   - 可扩展财务对账功能

7. **数据导出**
   - 仅支持Excel导入，未实现报表导出
   - 可增加PDF/Excel导出功能

## 数据库位置

SQLite数据库文件位于系统用户数据目录：
- macOS: `~/Library/Application Support/laundry-factory-system/laundry.db`
- Windows: `%APPDATA%/laundry-factory-system/laundry.db`
