# 光伏运维管理系统

## 系统概述

本系统针对光伏电站并网运维场景设计，核心解决并网资料管理、回款节点跟踪、发电异常工单处理三大痛点，替代传统 Excel + 微信群的协作方式。

## 核心功能

### 1. 站内概览（仪表盘）
- 今日发电量实时展示与发电曲线
- 并网资料、回款进度、工单数、备件库存统计卡片
- 各区域发电效率对比
- 最近动态时间线

### 2. 排班看板（拖拽分配）【高频核心场景】
- 待分配工单池可视化展示
- 工程师任务列，显示技能标签
- 支持拖拽工单向工程师分配（仅站长权限）
- 实时显示每人任务数量

### 3. 并网资料管理
- 资料列表与筛选（状态/类型/关键词）
- 审核流程：待审核 → 通过 / 驳回 / 要求补录
- 驳回原因、补录说明醒目展示
- 历史备注随时可查
- 文件列表展示

### 4. 回款节点跟踪
- 合同总金额、已回款、待回款统计
- 回款进度可视化进度条
- 节点时间线展示（预付款→并网验收款→竣工验收款→质保金）
- 当前进度与下一步说明
- 凭证材料上传记录
- 沟通记录留痕

### 5. 工单管理
- 工单统计：总数/待分配/处理中/停机时长/损失电量
- 多维度筛选（状态/优先级/类型）
- 工单详情：描述、位置、设备、处理人
- 停机时长与损失电量统计
- 备件领用记录
- 证据链（告警截图、现场照片）
- 状态历史（完整流转记录）
- 实时沟通备注

### 6. 备件管理
- 库存预警（低库存醒目提示）
- 备件列表与筛选
- 库存状态可视化（正常/低库存/缺货）
- 存放位置、单价、最近采购记录

## 启动方式

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发环境
```bash
npm run dev
```

启动后访问：
- 前端页面：http://localhost:3000
- 后端 API：http://localhost:3001

### 3. 切换角色测试
1. 访问 http://localhost:3000/login
2. 使用上表中不同账号登录
3. 体验不同角色看到的菜单和功能差异

## 关键设计点

### 异常处理链路
1. 发电异常 → 自动/人工创建工单
2. 站长拖拽分配 → 工程师接收
3. 现场处理 → 申请备件 → 上传照片证据
4. 添加处理备注 → 标记完成
5. 站长验收 → 填写关闭说明 → 关闭工单
6. 全链路可追溯（历史、备注、证据）

### 信息不丢失设计
- 驳回原因：资料详情页红色醒目提示
- 补录说明：橙色提示框展示
- 历史备注：每个模块都有备注区
- 状态历史：工单完整流转记录
- 责任人记录：每个操作记录操作人
