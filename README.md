# 礼品定制 - 打样确认与量产排期系统

基于 Vue 3 + Vite + TypeScript + Pinia + Tailwind CSS 的礼品定制行业管理平台，解决打样确认、量产排期和售后补单的全流程管理问题。

## 核心功能

### 1. 角色适配工作台
- **项目商务**：查看全部订单推进、总览看板、发起退款审批
- **打样跟单**：打样确认全流程操作、版本对比、发起异常标记
- **仓配协调**：量产排期操作、发货管理、异常回查与处理

### 2. 订单双轨视图
- **打样确认流程**：报价 → 寄样 → 客户确认 → 版本锁定
- **量产排期流程**：排期 → 生产 → 质检 → 发货
- **版本时间线**：样品确认版本的可视化时间线，每次确认变更留痕

### 3. 异常处理抽屉
- **版本覆盖告警**：确认版本被回退或覆盖时触发，展示新旧版本差异
- **拆单漏件检测**：拆单发货时自动比对明细，发现漏件自动标记
- **退款责任链**：退款申请必须填写责任方，逐级审批并留痕

## 演示数据说明

系统内置 6 条演示订单，包含多个可直接触发异常处理的场景：

### 1. 版本覆盖告警（已解决）
- **订单**：LP202405001 - 腾讯科技 定制年会礼品套装
- **说明**：客户在版本锁定前要求更换颜色，从深棕色改为经典黑
- **操作**：点击异常预警可查看历史处理记录

### 2. 拆单漏件检测（待处理）
- **订单**：LP202405002 - 阿里巴巴 员工福利保温杯
- **说明**：发货1200件，实际发出1150件，缺少50件
- **操作**：点击异常预警 → 记录处理措施 → 标记解决

### 3. 退款责任链（待审批）
- **订单**：LP202405003 - 字节跳动 定制笔记本礼盒
- **说明**：客户反馈100本笔记本印刷瑕疵，申请退款4,250元
- **操作**：切换到「张经理（项目商务）」角色 → 点击异常 → 审批通过/拒绝

- **版本覆盖**：进入已锁定版本的订单 → 点击「改版」按钮 → 填写变更原因
- **拆单漏件**：进入待发货订单 → 点击「发货操作」→ 实际发货数量填写小于订单数量
- **退款申请**：切换到商务角色 → 进入任意订单 → 点击「发起退款」

## 刻意简化说明

以下功能在本次演示中做了简化处理：

### 1. 用户认证
- 不实现完整登录系统
- 通过页面顶部角色切换器模拟不同角色
- 无密码验证、无 token 机制

### 2. 文件上传
- 样品照片使用 picsum.photos 占位图
- 不支持真实文件上传功能
- 无图片压缩、裁剪等处理

### 3. 通知推送
- 不接入 WebSocket 实时推送
- 异常预警通过页面内状态更新展示
- 无邮件、短信等通知渠道

### 4. 数据持久化
- 使用 localStorage 做数据持久化
- 清除浏览器缓存后数据会重置
- 无后端数据库存储

### 5. 权限控制
- 仅做 UI 层面的按钮显隐控制
- 不做接口级鉴权校验
- 无细粒度的权限矩阵

### 6. 打印与导出
- 不支持报价单、发货单打印
- 无 Excel/PDF 导出功能
- 无报表生成功能

## 异常测试指引

### 版本覆盖流程测试
1. 切换到「李跟单（打样跟单）」角色
2. 进入「LP202405006 - 小米科技」订单详情
3. 确认样品 → 锁定版本
4. 点击「改版」按钮
5. 填写变更原因并提交
6. 查看异常预警中新产生的版本覆盖告警

### 拆单漏件流程测试
1. 切换到「王仓管（仓配协调）」角色
2. 进入「LP202405005 - 华为」订单详情
3. 安排排期 → 开始生产 → 质检通过
4. 点击「发货操作」
5. 实际发货数量填写 500（少于 600）
6. 提交后查看自动触发的漏件检测异常

### 退款审批流程测试
1. 切换到「张经理（项目商务）」角色
2. 进入「LP202405004 - 美团」订单详情
3. 点击「发起退款」
4. 填写退款金额和原因
5. 在异常预警中找到新产生的退款待审批项
6. 进行审批操作
