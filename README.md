
# 美术馆运营管理系统

## 项目概述

整合展品借调、票务核销、异常处理三大业务模块的美术馆运营管理前端系统，解决多业务协同断层、异常处理依赖人工记忆、追溯审计困难等痛点。

## 技术栈

- **框架**: Vue 3.4 + TypeScript
- **构建工具**: Vite 5.2
- **状态管理**: Pinia 2.1
- **路由**: Vue Router 4.3
- **样式**: TailwindCSS 3.4
- **图表**: ECharts 5.5
- **图标**: Lucide Vue Next

## 快速启动

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问地址: http://localhost:3001

### 生产构建

```bash
npm run build
```

## 功能模块

### 1. 运营看板 `/dashboard`
- KPI 统计卡片（进行中借调、今日核销、待处理异常、已完成借调）
- 展品状态分布环形图
- 异常处理队列（优先级排序）

### 2. 展品借调 `/borrow`
- 借调单列表展示与搜索筛选
- 布展进度时间线
- 展品清单详情
- 异常快速跳转

### 3. 票务核销 `/ticket`
- 订单列表选择
- 核销工作台（批量核销）
- 异常票据处理入口

### 4. 追溯回查 `/trace`
- 全链路操作日志
- 多维度筛选查询
- 异常记录直接跳转

## 测试账号/角色

系统支持三种角色切换（右上角用户头像切换）：

| 角色 | 权限说明 |
|------|----------|
| **馆务经理** | 全局查看权限、数据统计分析 |
| **票务专员** | 票务核销操作、明细处理 |
| **活动执行** | 异常领取处理、追溯回查 |

## 演示异常场景

系统预置 5 条可直接触发的异常场景：

1. **展品逾期未归还** - 宋代山水画卷专题展借调单
2. **核销数量与台账不符** - VIP会员专场活动票务
3. **签到率异常低** - 周末艺术讲座
4. **展品状态与实际位置不符** - 甲骨文特展借调单
5. **紧急插单导致进度冲突** - 明清瓷器精品展布展

## 核心交互

### 异常处理流程
1. 点击异常卡片或通知铃铛打开**异常处理抽屉**
2. 切换到「活动执行」角色
3. 点击「领取处理」分配给自己
4. 添加处理备注记录沟通内容
5. 问题解决后点击「标记解决」
6. 最终「关闭归档」完成闭环

### 异常抽屉功能
- 异常详情展示（类型、描述、关联单据）
- 处理记录时间线
- 实时添加处理备注
- 角色权限控制操作按钮

## 刻意简化的部分

1. **用户认证** - 省略登录流程，直接角色切换模拟权限
2. **后端对接** - 全部使用前端 Mock 数据，无真实 API 调用
3. **消息推送** - 页面内红点提示替代实时推送
4. **文件导出** - 追溯回查页面省略报表导出功能
5. **数据持久化** - 刷新页面数据重置（未接入 localStorage）
6. **扫码功能** - 票务核销仅支持批量选择，无真实扫码

## 项目结构

```
src/
├── components/
│   ├── common/        # 通用组件（状态标签、统计卡片等）
│   ├── exception/     # 异常相关组件（核心抽屉）
│   └── layout/        # 布局组件（侧边栏、顶部栏）
├── mock/              # Mock 数据
├── stores/            # Pinia 状态管理
├── types/             # TypeScript 类型定义
├── views/             # 页面组件
├── router/            # 路由配置
├── App.vue
├── main.ts
└── style.css
```
