# 🎞️ 胶片冲印会员寄存与到期提醒管理系统

专为胶片冲印工作室打造的本地桌面管理系统，解决胶卷登记、冲扫进度跟踪、会员寄存与到期提醒等全流程管理问题。

## ✨ 核心特性

### 🎯 首页看板
- **待处理统计**：新登记、待冲扫胶卷一目了然
- **已驳回/待返工**：快速定位需要重新处理的胶卷
- **需回查**：返工过的胶卷历史记录
- **7天内到期**：即将到期的寄存胶卷提醒
- **今日处理量**：工作进度实时掌握

### 👥 会员管理
- 会员信息录入（姓名、手机号、微信号）
- 会员等级体系（普通/银卡/金卡/钻石），自动对应寄存期限
- 会员胶卷数量统计
- 搜索筛选功能

### 🎞️ 胶卷寄存管理
- **胶卷编号唯一性校验**：防止胶卷混号
- 完整胶卷信息：品牌、类型、ISO、格式、张数、冲扫工艺、扫描分辨率、交付版本
- **交付版本标记**：标准版/高清版/RAW原片，防止错发
- 加急标记
- 状态流转：已登记 → 待冲扫 → 冲扫中 → 待返工 → 待交付 → 已交付/寄存中
- 返工次数记录与驳回原因追踪

### 🔄 冲扫进度跟踪
- 可视化状态步骤条
- 完整处理记录时间线
- 操作人记录
- 驳回原因必填
- 返工说明记录

### 🔔 到期提醒系统
- **自动计算到期日期**：根据会员等级自动计算寄存到期日
- 多类型提醒：到期提醒、返工提醒、驳回提醒、待处理
- 优先级标记：高/中/低
- 一键标记已处理
- 倒计时显示

### 📊 操作日志审计
- 完整操作记录：创建、更新、删除、登记、冲扫、交付等
- 模块分类筛选
- 时间范围查询
- 操作人追踪
- 为赔付纠纷提供完整证据链

### 💾 本地数据管理
- **SQLite本地数据库**：数据安全，不依赖网络
- **CSV批量导入**：支持从登记本批量导入胶卷数据
- **数据导出**：会员、胶卷、处理记录一键导出CSV
- **数据库备份**：一键创建完整备份
- **数据恢复**：从备份文件恢复数据
- **导入模板下载**：标准CSV模板

## 🛠️ 技术栈

- **桌面框架**：Electron 28
- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite 5
- **UI组件**：Ant Design 5
- **本地数据库**：better-sqlite3
- **CSV处理**：Papa Parse
- **日期处理**：Day.js

## 📦 安装与运行

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 本地启动

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器（会自动打开应用窗口）
npm run dev
```

**启动路径**：项目根目录执行 `npm run dev`

**端口**：开发服务器运行在 http://localhost:5920

### 构建打包

```bash
# 构建 macOS dmg 安装包
npm run build

# 仅构建目录（不打包）
npm run build:dir
```

**输出路径**：`release/{版本号}/`

## 🚀 快速上手

### 初始化方式

1. **首次启动**：应用启动后会自动创建数据库并初始化演示数据
2. **演示数据**：包含5个会员、8条胶卷记录、4条待处理提醒
3. **数据位置**：
   - macOS: `~/Library/Application Support/film-storage-manager/data/film_storage.db`
   - 备份位置: `~/Library/Application Support/film-storage-manager/backups/`

### 演示入口

应用启动后默认进入**首页看板**，可直接体验：

1. **首页看板**：查看各类待处理数据统计
2. **会员管理**：左侧菜单 → 会员管理，可新增/编辑/删除会员
3. **胶卷登记**：左侧菜单 → 胶卷寄存 → 登记胶卷
4. **冲扫处理**：点击胶卷编号进入详情页，执行状态操作
5. **到期提醒**：左侧菜单 → 到期提醒，查看并处理提醒
6. **批量导入**：胶卷寄存页面 → 批量导入按钮，选择CSV文件
7. **数据备份**：左侧菜单 → 数据管理 → 创建备份

## 📋 批量导入CSV格式

下载模板：数据管理页面 → 下载导入模板

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| memberName | 是 | 会员姓名 | 张三 |
| memberPhone | 是 | 会员手机号 | 13800138001 |
| filmNo | 是 | 胶卷编号（唯一） | FLM202401001 |
| filmType | 是 | 胶卷类型 | 彩色负片 |
| filmBrand | 是 | 胶卷品牌 | Kodak |
| iso | 是 | ISO感光度 | 400 |
| format | 是 | 格式 | 135 |
| shots | 是 | 张数 | 36 |
| processType | 否 | 冲扫工艺，默认C-41 | C-41 |
| scanResolution | 否 | 扫描分辨率，默认3000dpi | 3000dpi |
| deliveryVersion | 否 | 交付版本，默认standard | standard |
| isUrgent | 否 | 是否加急，0/1，默认0 | 0 |
| storageStartDate | 否 | 寄存开始日期，默认当天 | 2024-01-01 |
| storageEndDate | 否 | 到期日期，默认按会员等级 | 2024-07-01 |
| remark | 否 | 备注 | 客户要求调色 |

> 💡 提示：如果会员手机号不存在，系统会自动创建普通会员

## 🔒 数据安全

1. **本地存储**：所有数据保存在本地，不上传云端
2. **唯一约束**：胶卷编号数据库唯一索引，防止重复
3. **操作审计**：所有增删改操作记录日志，可追溯
4. **备份机制**：支持一键备份和恢复
5. **WAL模式**：SQLite WAL模式，提高并发性能和数据安全性

## 💡 使用建议

1. **每日检查**：上班后先看首页看板，处理高优先级提醒
2. **胶卷编号规则**：建议使用 `FLM + 年份 + 序号` 格式，如 FLM202401001
3. **定期备份**：建议每周五下班前进行一次数据库备份
4. **导入前校验**：批量导入前先检查胶卷编号是否重复
5. **备注要详细**：驳回原因和返工说明尽量详细，方便后续追溯

## 🐛 常见问题

**Q: 应用打不开怎么办？**
A: 检查 Node.js 版本是否 >= 18，删除 node_modules 后重新安装依赖。

**Q: 数据不小心删了能恢复吗？**
A: 如果之前做过备份，可以在数据管理页面恢复；没有备份则无法恢复，请定期备份。

**Q: 批量导入失败怎么办？**
A: 导入完成后会显示失败详情，根据错误信息修正CSV后重新导入。已成功的数据不会重复导入。

**Q: 胶卷编号填错了能改吗？**
A: 为了数据一致性，胶卷编号一旦创建不允许修改，建议删除后重新登记。
