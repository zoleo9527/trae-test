# 图书发行管理系统

## 项目概述

这是一个完整的图书发行-新书铺货与回款跟踪管理系统，旨在解决传统手工操作中铺货、退货、回款数据割裂的问题，实现业务全链路数字化管理。

## 技术栈

- **前端**: React 18 + Vite + Tailwind CSS
- **后端**: FastAPI + SQLAlchemy + SQLite
- **状态管理**: React Hooks
- **路由**: React Router DOM

## 核心功能

### 1. 工作台 (Dashboard)
- 关键业务指标概览（铺货总数、待回执确认、待处理退货、待确认回款、待处理异常）
- 销售、退货、回款金额统计
- 最近铺货记录和待处理异常快速查看

### 2. 铺货管理 (Distribution)
- 双栏详情台交互：左侧列表 + 右侧详情
- 铺货单创建、查看、状态管理
- 收货回执确认/丢失标记
- 关联退货记录、回款记录、渠道反馈、异常记录
- 搜索和状态筛选功能

### 3. 退货处理 (Return)
- 退货单列表和详情查看
- 退货收货确认
- 数量差异标记（退货口径不一致处理）
- 关联铺货单信息

### 4. 回款跟踪 (Payment)
- 回款记录管理
- 财务确认流程
- 自动对账计算（应结 vs 实结）
- 金额差异预警

### 5. 异常处理 (Exception)
- 全链路异常统一管理
- 异常类型：回执丢失、数量差异、金额不符
- 异常处理流程：待处理 → 处理中 → 已解决
- 内置处理建议指引

## 快速开始

### 环境要求

- Node.js >= 16.0.0
- Python >= 3.8

### 安装依赖

#### 后端
```bash
cd backend
pip install -r requirements.txt
```

#### 前端
```bash
npm install
```

### 初始化数据库和演示数据

```bash
cd backend
python seed_data.py
```

### 启动服务

#### 启动后端服务 (端口 8000)
```bash
cd backend
uvicorn main:app --reload
```

#### 启动前端服务 (端口 3000)
```bash
npm run dev
```

### 访问系统

打开浏览器访问: http://localhost:3000

## 刻意简化的设计说明

为了快速验证业务链路，本版本做了以下简化设计，在实际生产环境中建议补充：

### 1. 安全认证
- **当前**: 无登录认证，模拟固定角色视角
- **建议**: 接入 JWT/OAuth2.0 认证，实现基于角色的权限控制 (RBAC)

### 2. 新建/编辑表单
- **当前**: 仅实现列表查看和状态变更操作
- **建议**: 补充完整的铺货单创建、退货登记、回款录入等表单流程

### 3. 数据完整性校验
- **当前**: 基础字段校验
- **建议**: 增加业务规则校验（如退货数量不能大于铺货数量）

### 4. 消息通知
- **当前**: 无实时通知
- **建议**: 接入 WebSocket 或轮询机制，实现异常待办实时提醒

### 5. 审批流
- **当前**: 状态直接变更
- **建议**: 引入工作流引擎，支持多级审批流程

### 6. 审计日志
- **当前**: 仅记录创建/更新时间
- **建议**: 完整操作日志，记录每个状态变更的操作人、时间、原因

### 7. 报表导出
- **当前**: 无导出功能
- **建议**: 支持 Excel/PDF 导出，满足财务对账和存档需求

### 8. 数据分页
- **当前**: 一次性加载全部数据
- **建议**: 实现服务端分页，支持大数据量场景

## 核心设计特点

### 双栏详情台交互
- 左侧列表快速浏览，右侧详情深度处理
- 支持拖拽调整左右宽度比例
- 减少页面跳转，提升操作效率

### 业务链路打通
- 铺货单 → 退货单 → 回款单 全链路关联
- 异常记录与业务单据绑定
- 从任意单据可追溯完整业务上下文

### 异常前置处理
- 回执丢失、数量差异、金额不符等典型异常场景内置识别
- 每个异常类型提供处理建议指引
- 统一的异常处理工作台，避免月底集中对账
