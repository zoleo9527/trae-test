# 珠宝门店 - 定制订单与镶嵌进度管理系统

## 项目概述

面向珠宝门店的定制订单管理系统，解决传统纸单、微信沟通导致的订单追踪困难、异常处理混乱、交接留痕不足等问题。

## 核心功能

### 1. 仪表盘 (Dashboard)
- 数据概览卡片：今日订单、进行中、异常订单、完成率
- 订单趋势图表
- 待办事项列表（支持优先级排序）
- 最近订单快速预览
- 异常预警提醒

### 2. 订单管理
- **多维度筛选**：按状态、类型、搜索（订单号/客户/电话）
- **双栏详情台**：点击订单右侧展开详情面板，无需跳转
- **进度追踪**：7 道工序节点时间线，实时状态更新
- **订单详情页**：完整信息展示、价格明细、操作记录、改款历史

### 3. 异常处理中心
- 异常分级（紧急/高/中/低）
- 处理流程跟踪（待处理→处理中→已解决→已关闭）
- 原因分析、解决方案、赔付金额记录
- 处理历史时间线

### 4. 交接管理
- 交接类型：收货/转送/交付/退回
- 货品清单明细
- 照片留痕与签名确认
- 完整溯源记录

## 启动方式

```bash

# 启动开发服务器

npm run build

# 预览生产构建

```

## 技术栈

- **框架**：Nuxt 3 (Vue 3 + TypeScript)
- **状态管理**：Pinia
- **样式**：Tailwind CSS 3 + SCSS
- **图标**：Lucide Vue Next
- **日期处理**：date-fns
- **字体**：Playfair Display (标题) + Inter (正文)

## 设计风格

- **主色调**：深香槟金 (#B8860B) - 体现珠宝行业奢华品质
- **辅助色**：墨蓝 (#1a365d) - 专业稳重
- **强调色**：珊瑚红 (#E63946) - 异常状态提醒
- **布局**：卡片式、双栏详情台、精致阴影、金色分隔线
- **动效**：页面渐入、平滑滑动、节点脉冲、微交互

## 刻意简化的部分

1. **后端服务**：使用 Mock 数据，无真实 API
2. **用户认证**：前端模拟登录，无 JWT/OAuth
3. **文件上传**：使用占位图标，无真实 OSS 存储
4. **消息推送**：无实时通知功能
5. **权限控制**：前端模拟，无后端校验
6. **打印功能**：UI 按钮已预留，未实现实际打印
7. **数据持久化**：刷新页面数据重置
8. **图片资源**：无真实商品图片，使用图标占位

## 核心流程

1. **订单创建** → 导购录入客户信息和定制要求
2. **工序流转** → 每完成一个节点更新进度状态
3. **异常触发** → 遇到问题标记异常，进入处理流程
4. **售后跟进** → 原因分析→方案确认→执行处理→结案
5. **货品交接** → 每次交接必须登记，照片+签名留痕
6. **店长监控** → 通过仪表盘掌握整体运营
