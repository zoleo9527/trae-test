# 自助洗车 - 设备补货与耗材盘点系统

## 快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 打开浏览器访问
http://localhost:3000
```

## 角色切换说明

系统内置三个角色，在左侧边栏的用户信息下方可以一键切换：

| 角色 | 权限与视角 |
|------|-----------|
| **运营主管** | 全局视角，可查看所有工单、站点状态、库存预警；可派单、审核、升级处理；可审核退款申请 |
| **巡检员** | 只看到分配给自己的工单和待处理工单；可开始处理、申请审核、升级问题；可提交补货申请 |
| **客服** | 看到自己创建的工单和投诉退款类工单；可创建报修工单、录入退款申请、添加备注 |

## 核心模块说明

### 1. 运营总览
- 全局工单统计（待处理/处理中/已完成/紧急升级）
- 最新工单动态列表
- 站点健康度监控
- 耗材库存预警
- 升级告警提示

### 2. 工单管理
- 四类工单：设备维修、耗材补货、例行巡检、投诉退款
- 完整状态流转：待处理 → 已派单 → 处理中 → 审核中 → 已完成/已驳回
- 支持紧急升级机制
- 每张工单包含：
  - 基本信息（站点、设备、优先级）
  - 状态流转时间线（带操作人和时间）
  - 证据附件（图片、视频、文本）
  - 驳回原因与补录说明
  - 历史备注（所有人可见、可追加）
  - 关联退款信息

### 3. 耗材盘点
- 全站点总览模式 / 单站点详情模式
- 库存状态可视化（正常/偏低/缺货）
- 安全库存线预警
- 上次补货时间追踪
- 一键申请补货

### 4. 排班调度
- **拖拽排班**：拖拽排班卡片调整顺序，自动更新时间段
- 按巡检员分栏展示
- 排班状态（待执行/进行中/已完成/已跳过）
- 工单与排班关联
- 待分配工单池

### 5. 退款申诉
- 退款申请全链路追踪
- 证据链整合（附件、客户信息、通话记录）
- 审核操作（通过/驳回 + 驳回原因）
- 驳回原因与补录说明关联展示
- 退款状态与工单状态联动

## 演示数据说明

已预置完整的演示数据，覆盖各种场景：

| 数据类型 | 说明 |
|---------|------|
| **站点** | 4个洗车站点，覆盖正常、预警、故障、维护四种状态 |
| **设备** | 8台设备，包含在线、离线、故障、维护状态 |
| **耗材** | 5种耗材，包含正常、库存低、缺货状态 |
| **工单** | 7张工单，覆盖所有类型和状态流转阶段 |
| **退款申请** | 3条退款记录，包含待审核、已通过、已驳回 |
| **排班** | 5条排班记录，覆盖不同状态和时段 |
| **历史备注** | 4条备注示例，展示不同角色的沟通记录 |

### 推荐测试路径

1. **客服视角**：查看投诉退款工单，添加备注
2. **主管视角**：审核退款申请，驳回并填写原因
3. **巡检员视角**：处理分配的工单，上传证据，申请审核
4. **主管视角**：审核工单，查看状态流转历史
5. **排班调度**：拖拽调整排班顺序，验证时间自动更新
6. **耗材盘点**：切换不同站点查看库存详情

## 已做轻量处理的边界（待扩展）

以下模块当前做了简化实现，生产环境需要补充：

| 模块 | 当前状态 | 生产环境需要补充 |
|-----|---------|----------------|
| **用户认证** | 纯前端角色切换，无真实登录 | OAuth/SSO、权限校验、会话管理 |
| **数据持久化** | Zustand 内存状态，刷新丢失 | 后端API、数据库、缓存 |
| **文件上传** | 仅展示预置图片，无上传功能 | OSS存储、文件校验、压缩处理 |
| **消息通知** | 无实时通知 | WebSocket、消息推送、邮件短信 |
| **数据导出** | 无导出功能 | Excel/PDF导出、打印模板 |
| **统计报表** | 仅基础概览 | 多维度报表、趋势分析、数据可视化 |
| **移动端适配** | 未做响应式优化 | 小程序/APP、移动端交互优化 |
| **批量操作** | 仅单个工单处理 | 批量派单、批量审核、批量导出 |
| **流程配置** | 状态流转固定 | 可配置工作流、自定义审批链 |
| **审计日志** | 仅工单内历史 | 全局操作审计、日志追溯 |

## 技术栈

- **框架**: Next.js 14 (App Router)
- **语言**: TypeScript
- **样式**: TailwindCSS
- **状态管理**: Zustand
- **拖拽**: @dnd-kit
- **图标**: Lucide React
- **日期处理**: date-fns
