# 洗涤工厂 - 门店交接与回单核验系统

解决收衣单、返洗记录与交接回单散落各处的管理断层问题，让厂长、质检员、门店交接员在同一处理面上各司其职，消除污损争议、批次混洗和赔付扯皮。

## 快速开始

### 1. 安装依赖

```bash
pnpm install
```

### 2. 启动开发服务器

```bash
pnpm dev
```

### 3. 访问系统

打开浏览器访问：**http://localhost:5173**

---

## 功能概览

### 三大核心页面

| 页面 | 路径 | 功能说明 |
|------|------|----------|
| 首页仪表盘 | `/` | 待处理/已驳回/需回查数据一览，超时预警，今日待办 |
| 订单流水线 | `/pipeline` | 六列看板视图，实时跟踪全流程状态 |
| 批次追踪 | `/batches` | 洗涤批次管理，单件衣物溯源 |

### 三种用户角色

系统支持一键切换角色，体验不同岗位的工作视角：

| 角色 | 核心职责 | 主要操作 |
|------|----------|----------|
| 👑 **厂长** | 全局管控 | 分拣指派、超时监控、批次管理、赔付审批 |
| 🛡️ **质检员** | 质量把控 | 质检登记、返洗判定、污损拍照记录 |
| 🏪 **门店交接** | 收发货确认 | 交接确认、回单核验、退回登记 |

**角色切换方式**：点击左侧导航栏底部的角色选择器即可切换。

## 核心操作流程

### 1. 厂长 - 分拣指派

1. 进入「首页仪表盘」查看今日待办
2. 点击「分拣中」的订单卡片
3. 在右侧处理台选择洗涤批次
4. 确认分拣，订单进入洗涤环节

### 2. 质检员 - 质检处理

1. 切换角色为「质检员」
2. 在「订单流水线」找到「质检中」的订单
3. 点击卡片打开处理台，选择：
   - **质检通过**：进入门店交接环节
   - **需要返洗**：选择返洗原因，进入返洗流程
   - **发现污损**：拍照取证，记录污损位置和描述

### 3. 门店交接 - 回单核验

1. 切换角色为「门店交接」
2. 查看「待交接」和「核验中」的订单
3. 交接确认：确认衣物已送出
4. 回单核验：
   - 核验通过 → 订单完成
   - 申请退回 → 填写原因，订单驳回重处理

## 侧边处理台使用说明

右侧滑出的处理台是系统的核心操作区，包含三个标签页：

| 标签 | 内容 |
|------|------|
| **处理** | 当前环节的操作表单和按钮 |
| **流转记录** | 订单的完整时间线和处理人 |
| **证据链** | 污损照片、返洗记录等凭证 |

## 技术栈

- **框架**：React 18 + TypeScript

- **路由**：React Router v7
- **状态管理**：Zustand
- **样式**：Tailwind CSS
- **图标**：Lucide React
- **动画**：Framer Motion
