# 🎁 礼品定制-客户报价与审批留痕系统

## 项目背景

解决礼品定制行业的协作痛点：
- **版本覆盖问题**：报价多次修改后历史版本丢失
- **拆单漏件**：分批发货后数量核对困难
- **责任链缺失**：退款售后时找不到决策依据
- **信息割裂**：各部门各管一段，核细节时需要翻截图和语音

## 技术架构

## 核心设计理念

**按真实协作流程建模**：
1. **商务部**（张三）：创建报价、判断价格、提交审批
2. **打样部**（李四）：执行打样、上传样照、记录反馈
3. **仓配部**（王五）：复核发货、记录物流、拆单处理
4. **审批部**（赵六）：价格审批、退款审批
5. **客服部**（钱七）：售后处理、退款申请

**所有动作留痕串联**：
- 报价版本历史 → 审批记录 → 打样反馈 → 发货明细 → 退款审批 → 完整操作日志

## 核心功能

### 1. 多条件筛选区
- 状态筛选：草稿/待审批/打样中/量产中/部分发货/已完成
- 客户名称：模糊搜索
- 产品类型：模糊搜索
- 日期范围：创建时间区间
- 分页浏览

### 2. 报价单详情（7个标签页）

| 标签 | 内容 | 解决痛点 |
|------|------|---------|
| **基本信息** | 客户、价格、数量、交货期 | 核心信息一目了然 |
| **版本历史** | 每次修改的快照+修改原因+修改人 | ✅ 解决版本覆盖问题 |
| **审批留痕** | 审批时间+意见+审批人 | ✅ 责任链完整记录 |
| **打样记录** | 样照+客户反馈+确认人 | ✅ 打样效果有据可查 |
| **发货记录** | 拆单标识+发货明细+物流+复核人 | ✅ 拆单发货不漏件 |
| **退款售后** | 退款金额+原因+申请人+审批人 | ✅ 售后责任链完整 |
| **操作日志** | 全流程时间线+操作人 | ✅ 不用翻截图找证据 |

## 实现取舍点（Trade-offs）

### 1. 数据库选择：SQLite
**✅ 优点：**
- 零配置，单文件即可运行
- 适合演示和小型团队
- 数据备份简单（复制文件即可）

**❌ 限制：**
- 不支持高并发写入
- 横向扩展困难

**→ 后续扩展：** 迁移到 PostgreSQL/MySQL

### 2. 权限设计：简化角色模拟
**✅ 优点：**
- 演示方便，无需登录
- 专注流程而非认证

**❌ 限制：**
- 无真实用户认证
- 操作人ID硬编码（当前用户固定为张三）

**→ 后续扩展：** 接入 JWT/OAuth2 登录，基于角色的权限控制（RBAC）

### 3. 文件上传：路径占位
**✅ 优点：**
- 不依赖对象存储服务
- 演示时无需真实图片

**❌ 限制：**
- 打样照片为占位符
- 无真实文件上传功能

**→ 后续扩展：** 集成阿里云OSS/腾讯云COS

### 4. 流程状态：线性推进
**✅ 优点：**
- 业务逻辑清晰
- 符合80%的常规场景

**❌ 限制：**
- 不支持复杂回退流程
- 无并行审批

**→ 后续扩展：** 引入工作流引擎（如 Activiti/Camunda）

## API 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/quotes` | 报价单列表（支持多条件筛选） |
| GET | `/api/quotes/:id` | 报价单详情（含所有关联数据） |
| POST | `/api/quotes` | 创建报价单 |
| PUT | `/api/quotes/:id` | 修改报价（自动生成版本） |
| POST | `/api/quotes/:id/submit-approval` | 提交审批 |
| POST | `/api/quotes/:id/approve` | 审批通过/拒绝 |
| POST | `/api/proofs/quote/:quoteId` | 创建打样任务 |
| PUT | `/api/proofs/:id/upload` | 上传打样照片 |
| PUT | `/api/proofs/:id/feedback` | 客户反馈确认 |
| POST | `/api/shipments/quote/:quoteId` | 创建发货单 |
| PUT | `/api/shipments/:id/check` | 仓配复核发货 |
| POST | `/api/refunds/quote/:quoteId` | 申请退款 |
| PUT | `/api/refunds/:id/approve` | 退款审批 |
| GET | `/api/users` | 用户列表 |
| GET | `/api/stats` | 统计看板数据 |
