# 留学服务追踪系统

## 项目概述

这是一个基于 Electron + SQLite 的桌面应用，用于留学服务行业的选校方案与材料收集全流程追踪管理。

### 核心设计理念

1. **链路追踪而非功能分区**：选校方案与材料收集在同一学生档案中形成完整时间线，可来回追溯
2. **角色视图分离但数据统一**：顾问主管、文案老师、签证助理使用同一数据源，不同视图权限
3. **工具化桌面体验**：打印回执、缓存恢复、批量处理等桌面原生功能
4. **异常场景优先**：针对截止日漏盯、补件版本混乱、退款协商缺上下文等高频痛点设计

## 功能模块

### 1. 工作台 (Dashboard)

- **统计卡片**：总学生数、待处理材料、7天内截止、异常状态
- **截止日提醒**：按紧急程度排序，3天内红色预警
- **待审核材料列表**：快速查看需要处理的材料
- **异常提醒**：错过截止日、退款待处理、材料被退回

### 2. 学生管理

- 学生基本信息管理
- 点击学生查看完整档案
- 搜索过滤功能

### 3. 学生详情 (核心链路)

**四个标签页形成完整追踪链：**

1. **基本信息**：学生个人档案
2. **选校方案**：冲刺/主申/保底校分层，截止日期追踪
3. **材料清单**：版本管理，退回后可新建版本
4. **时间线**：选校、材料、文书、签证、操作日志的完整时间轴

### 4. 材料中心

- 材料列表与状态筛选
- 单份通过/退回操作
- **批量审核**：勾选多份材料一键通过
- 版本历史追踪

### 5. 文书管理

- 文书创建与分配
- 版本与状态追踪
- 截止日期提醒

### 6. 签证追踪

- 签证流程管理
- 预约/面试/结果日期记录
- 状态追踪

### 7. 退款管理 (仅主管)

- 退款申请列表
- 批准/拒绝操作
- 完整上下文记录

### 8. 操作日志 (仅主管)

- 全系统操作审计
- 操作人、时间、模块、详情记录

## 桌面增强功能

### 1. 打印回执

在学生详情页点击「打印回执」，自动生成包含以下内容的正式回执：
- 学生基本信息
- 选校方案清单
- 材料状态统计
- 打印时间戳

### 2. 缓存恢复

- 登录状态持久化存储
- 窗口位置与大小记忆
- 刷新页面不丢失会话

### 3. 批量处理

- 材料批量审核通过
- 确认弹窗防止误操作

## 演示数据说明

系统首次启动自动生成演示数据，包含以下异常场景：

### 1. 张明 (正常推进但有问题)
- 3所学校申请（斯坦福冲刺、伯克利主申、USC保底）

### 2. 李华 (新申请)
- 刚创建档案，需要添加选校和材料

### 3. 王芳 (高危警告)
- 墨尔本大学申请**已错过截止日**
- 学生沟通不畅标记
- **异常点**：截止日漏盯场景

- 退款申请待处理（15000元）
- GPA不足申请难度大
- 签证流程暂停
- **异常点**：退款协商缺完整上下文场景

## 数据库位置

SQLite 数据库文件位于系统用户数据目录：

- **macOS**: `~/Library/Application Support/study-abroad-tracker/study-abroad.db`
- **Windows**: `%APPDATA%/study-abroad-tracker/study-abroad.db`

## 刻意简化的部分

为了保持演示版本简洁，以下功能做了简化：

1. **文件上传**：未实现真实文件上传，仅记录元数据
2. **富文本编辑**：文书内容采用纯文本存储
3. **邮件通知**：截止日提醒仅在应用内显示，未对接邮件服务
4. **权限细化**：角色权限为粗粒度，未实现细粒度按钮级控制
5. **数据同步**：纯本地SQLite，未实现多端同步
6. **密码加密**：演示版密码明文存储，生产环境需加密
7. **导出Excel**：仅支持打印回执，暂不支持Excel导出
8. **消息推送**：无实时消息，需手动刷新查看最新状态

## 技术栈

- **框架**: Electron 28
- **数据库**: better-sqlite3
- **缓存**: electron-store
- **前端**: 原生 HTML/CSS/JavaScript (无框架依赖)
- **Excel**: xlsx (预留)
