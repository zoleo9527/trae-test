# 农机合作社管理系统

## 项目概述

围绕**地块进度与回访评价**两个核心环节，解决合作社"入口散、提醒弱、历史难找"的痛点。

## 快速启动

### 1. 安装依赖

```bash
pnpm install
# 或
npm install
# 或
yarn install
```

### 2. 启动开发服务

```bash
pnpm dev
# 或
npm run dev
```

访问：`http://localhost:1420`

### 3. 演示账号

| 角色 | 用户名 | 密码 | 说明 |
|------|--------|------|------|
| 合作社理事 | `director` | `123456` | 查看全局进度、审批补贴、查看历史 |
| 调度员 | `dispatcher` | `123456` | 创建任务、登记油料、管理补贴、处理预警 |
| 机手 | `operator` | `123456` | 查看任务、更新进度、回查历史 |

## 核心功能说明

### 🌱 地块进度看板（理事视角）
- 全局地块状态分布统计
- 实时作业进度一览
- 预警提醒集中处理

### 📋 作业调度处理（调度员视角）
- 新建/分配作业任务
- 油料消耗登记管理
- 补贴申请提交跟进
- 预警信息处理

### 🚜 机手作业回查
- 个人任务列表
- 进度更新上报
- 历史作业回看
- 评价反馈查看

## 演示数据链路

### 完整业务链路示例

```
地块登记 → 任务创建 → 机手执行 → 进度更新 → 油料登记
                                 ↓
                           补贴申请 → 理事审批
                                 ↓
                           农户评价 → 回复处理
```

### 演示数据包含

1. **5个地块**：覆盖不同状态（待执行/进行中/已完成/已延误）
2. **5个作业任务**：含进度、油料、备注信息
3. **3条油料记录**：关联任务与机手
4. **3条补贴申请**：待审核/已通过/已驳回
5. **2条回访评价**：含5星好评和2星差评及回复
6. **4条预警提醒**：延误、材料不齐、差评、维修
7. **8条操作历史**：完整状态变更追踪

## 断网缓存 & 历史回看

### 本地存储方案
- 基于 **IndexedDB** (idb-keyval) 实现本地持久化
- 数据完全离线可用
- 刷新页面数据不丢失

### 历史记录特点
- 全链路操作留痕
- 状态变更自动记录
- 责任人与时间戳完整
- 支持按类型筛选查看

- **存储**：IndexedDB (idb-keyval)
- **桌面端**：Tauri (可选)
- **日期**：dayjs

## 常见问题

### Q: 数据存在哪里？
A: 数据存储在浏览器的 IndexedDB 中，清除浏览器数据会丢失。

### Q: 如何重置演示数据？
A: 打开浏览器开发者工具 → Application → IndexedDB → 删除 farm-coop-db 数据库，刷新页面。

### Q: 不同角色看到的菜单不一样？
A: 是的，系统根据角色动态显示有权限的菜单项。

### Q: 可以在手机上使用吗？
A: 当前为桌面端优化设计，移动端可使用但体验未做适配。
