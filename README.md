# 船舶代理 - 补给申请与供应商对接系统

## 快速开始

### 启动方式

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

项目启动后访问：`http://localhost:3001`

## 核心功能说明

### 1. 预警看板（顶部）
- **待审核申请**：需要经理审核的申请数量
- **紧急需求**：标有"特急"的补给申请
- **证件截点提醒**：3天内到期的证件
- **付款提醒**：3天内到期的款项

### 2. 左侧申请列表
- 支持按状态筛选（全部/草稿/待审核/已审核/已驳回/供应商已分配/执行中/已完成/已结算）
- 支持搜索（申请编号、船名、港口）
- 卡片显示关键信息：船名、港口、靠泊日期、物资摘要、金额、处理人
- 特急申请有红色闪烁标识

### 3. 右侧详情面板
点击申请卡片后展开，包含4个标签页：

#### 基本信息
- 船舶与港口信息
- 补给物资清单（分类、规格、数量、紧急度）
- 供应商信息
- 费用信息（总金额、预付款、付款状态）

#### 证件管理
- 证件清单及截止日期
- 证件状态（待收取/已收到/已过期）
- 提醒节点配置
- 临近截止日期高亮显示

#### 状态追踪
- 完整的时间线展示
- 每个状态变更记录：状态、操作人、备注、时间

#### 沟通记录
- 系统自动记录（状态变更）
- 人工备注
- 驳回原因（红色背景）
- 加急提醒（黄色背景）
- 支持新增备注

### 4. 批量复核面板（代理经理专属）
- 一键全选/取消
- 支持批量通过
- 支持批量驳回（需填写统一原因）
- 显示物资摘要和关键信息

## 当前版本边界说明（轻量化处理）

### ✅ 已实现
- [x] 完整的申请状态流转（8个状态）
- [x] 三种角色及权限控制
- [x] 批量复核功能
- [x] 证件截点提醒
- [x] 垫付款跟踪
- [x] 供应商分配
- [x] 历史记录与沟通备注
- [x] 预警看板

### ⏸️ 暂未实现（可后续扩展）
- **新建/编辑申请表单**：当前仅支持查看和流转现有数据
- **后端接口对接**：当前使用本地模拟数据（Pinia Store）
- **用户登录认证**：直接切换角色，无密码验证
- **文件上传**：证件和发票仅展示名称，不支持上传
- **消息推送**：预警仅在页面内展示，无邮件/短信通知
- **数据导出**：不支持Excel/PDF导出
- **统计报表**：暂无数据分析和报表功能

## 工作流设计

```
草稿 → 待审核 → 已审核 → 供应商已分配 → 执行中 → 已完成 → 已结算
         ↓          ↓
       已驳回    （可重新提交）
```

每个节点：
- 记录操作人
- 记录时间戳
- 支持填写备注
- 自动记录到沟通日志
