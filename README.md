# 光伏运维巡检工单与发电预警系统

## 项目概述

光伏电站运维管理系统，解决巡检工单与发电预警数据割裂问题，实现发电异常告警、备件领用、工单处理全流程闭环管理。

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 6
- **样式方案**: TailwindCSS 3
- **状态管理**: Zustand
- **路由管理**: React Router 7
- **图标库**: Lucide React
- **图表库**: Recharts
- **日期处理**: date-fns

## 核心功能

### 1. 工作台 (Dashboard)
- 统计概览：待处理工单、活动告警、累计停机时长、工单完成率
- 待处理工单列表（含超时提醒）
- 发电预警快速查看
- 备件待审批统计

### 2. 工单管理 (WorkOrders)
- 工单列表展示，支持搜索和筛选
- 按状态、优先级筛选
- 点击工单打开右侧处理台
- 超时工单高亮显示

### 3. 右侧侧边处理台 (核心交互)
- **详情标签页**: 工单基本信息、关联发电预警、现场照片
- **处理记录标签页**: 时间线展示全流程处理记录
- **备件标签页**: 备件领用记录
- **操作区域**: 基于角色的状态流转操作
  - 工程师: 开始处理、申请备件、提交完成
  - 站长: 审核通过、退回重处理
  - 所有操作需填写处理备注

### 4. 发电预警 (Alarms)
- 告警统计卡片（全部、严重、重要、活动）
- 告警列表，支持等级和状态筛选
- 告警详情面板，含发电数据趋势图
- 支持从告警创建巡检工单

### 5. 备件管理 (SpareParts)
- 备件申请统计（全部、待审批、已通过）
- 备件申请列表，支持搜索和状态筛选
- 站长/内勤可审批备件申请

## 刻意简化的部分

为了演示目的，以下功能进行了简化：

1. **后端服务**: 使用Mock数据 + LocalStorage持久化，不搭建真实后端
2. **权限控制**: 前端模拟角色权限，无后端鉴权验证
3. **文件上传**: 模拟上传流程，不实际存储文件
4. **实时推送**: 无WebSocket，数据需手动刷新
5. **多电站**: 单电站数据，不做多租户隔离
6. **数据导出**: 前端模拟，不生成真实文件
7. **消息通知**: 无真实消息推送，仅UI展示
8. **用户管理**: 固定3个测试账号，不支持新增/编辑用户

## 典型操作流程演示

### 流程1: 工程师处理超时工单
1. 使用 `engineer / engineer123` 登录
2. 在工作台看到"组串C2通讯中断"已超时
3. 点击工单打开右侧处理台
4. 在"详情"标签页查看关联的发电预警
5. 输入备注"已到达现场，开始排查通讯模块"
6. 点击"开始处理"按钮
7. 状态变为"处理中"，处理记录自动添加

### 流程2: 工程师申请备件
1. 继续处理"组串C2通讯中断"工单
2. 输入备注"通讯模块损坏，需要更换"
3. 点击"申请备件"按钮
4. 工单状态变为"待备件"
5. 切换到"备件"标签页查看申请记录

### 流程3: 站长审核工单
1. 使用 `admin / admin123` 登录
2. 进入工单管理，点击"光伏板区域清洁完成"工单
3. 查看处理记录和现场照片
4. 输入备注"处理合格，同意关闭"
5. 点击"审核通过"按钮
6. 工单关闭，流程结束
