# 美术馆运营系统 - 文创补货与损耗记录

基于 Nuxt 3 构建的美术馆文创商品运营管理系统，整合了补货与损耗记录，解决入口散、提醒弱、历史难找的问题。

## 核心功能

### 1. 统一入口管理
- **文创补货与损耗整合页面**：不再分开两个系统，统一入口管理
- **联动日历视图**：按日期查看补货、损耗、活动、展览和客流高峰
- **商品库存总览**：实时查看库存状态和预警

### 2. 角色权限控制
系统内置三个角色，不同角色看到的信息和权限不同：

| 角色 | 权限 | 可见范围 |
|------|------|----------|
| 馆务经理 | 查看全部、创建、审批、编辑、删除、导出 | 所有字段 |
| 票务专员 | 创建、编辑 | 供应商、日期、库存相关 |
| 活动执行 | 创建、编辑 | 活动关联、损耗原因相关 |

### 3. 状态流转与历史追踪
每条记录都有完整的状态流转时间线：
- 待审批 → 已批准 → 处理中 → 已完成
- 异常状态标记与解决流程
- 每一步操作都记录：时间、操作人、备注

### 4. 智能筛选与搜索
- 多维度筛选：状态、类型、优先级、位置、日期范围
- 全文搜索：商品名称、SKU、备注、创建人
- 日历联动：点击日历日期自动筛选当天记录

### 5. 通知提醒系统
- 实时通知中心
- 未读数量角标
- 点击通知直接跳转到相关记录
- 支持全部标记已读

## 角色切换说明

在页面顶部导航栏，点击左侧的角色标签（显示当前角色名称）即可打开角色切换菜单。

**角色说明：**
- 🟢 **馆务经理**（张明远）- 拥有所有权限，可以审批、查看全部信息
- 🔵 **票务专员**（李票务）- 主要处理日常补货和现场损耗登记
- 🟡 **活动执行**（林小艺）- 主要处理活动相关的文创使用和损耗

## 页面功能说明

### 文创管理（首页）
- **统计卡片**：待审批、异常记录、本月补货、本月损耗
- **筛选栏**：搜索、状态筛选、类型筛选、优先级筛选、**位置筛选**、**日期范围筛选**
- **记录列表**：按更新时间倒序，显示关键信息（按角色权限显示不同字段）
- **详情面板**：点击记录展开右侧详情
  - 基本信息：商品、数量、位置、供应商等（按角色权限控制可见性）
  - **关联链路**：活动、订单号，用卡片式布局展示完整链路
  - 当前责任人：头像、姓名、角色
  - **完整链路追踪**：状态节点带图标，时间线卡片式展示，每个节点包含操作人、角色、时间、备注
  - 操作按钮：审批/驳回/解决

### 角色权限控制
| 角色 | 可见字段 |
|------|----------|
| 馆务经理 | 全部字段 |
| 票务专员 | 位置、供应商、日期、关联订单 |
| 活动执行 | 位置、关联活动、损耗原因 |

### 日历视图
- 月份视图，显示每天的事件
- 点击日期筛选当天的记录（联动到首页列表）
- **点击事件直接跳转到记录详情**（日历 → 详情双向联动）
- 新建补货/损耗记录时，自动添加到日历
- 图例说明：补货（蓝）、损耗（橙）、活动（紫）、展览（绿）、客流高峰（红）

### 商品库存
- 商品总数、库存预警数量、总价值
- 完整的商品列表
- 库存不足自动标红提醒

## 当前边界（轻量实现）

以下功能目前为轻量实现，后续可扩展：

1. **数据持久化**：当前使用 Pinia 内存存储，刷新页面重置
2. **真实后端**：模拟数据，无真实 API 调用
3. **用户认证**：角色切换为演示模式，无真实登录
4. **导出功能**：UI 预留，实际导出未实现
5. **图片上传**：损耗照片功能暂未实现
6. **消息推送**：当前为站内通知，无邮件/短信推送
7. **库存自动更新**：审批通过后库存不会自动变化
8. **分页功能**：列表当前展示全部，无分页
