# 船舶代理费用垫付与回款核对系统

## 项目概述

这是一个针对船舶代理行业的业务管理系统，核心解决**靠泊计划分散、费用垫付与回款核对脱节、入口不清晰**等痛点问题。

## 核心功能模块

### 1. 靠泊计划管理
- 船舶靠泊计划的创建、编辑和状态跟踪
- 关联服务（船员换班、补给等）统一管理
- 历史记录可追溯

### 2. 费用垫付与回款核对
- 垫付费用登记（关联靠泊计划和供应商）
- 回款登记与自动核对
- 逾期提醒与统计
- 回款沟通记录留存

### 3. 船员换班管理
- 上下船人员信息管理
- 证件审核状态跟踪
- 签证到期提醒

### 4. 补给管理
- 食品、燃油、物料补给申请
- 预估费用跟踪
- 交付日期提醒

### 5. 联动日历视图
- 靠泊日期、费用到期、证件到期、补给交付统一展示
- 按月查看，点击日期查看详情
- 事件类型颜色区分

### 6. 智能提醒中心
- 按优先级（紧急/普通/低）分类
- 支持按类型（靠泊/费用/证件/补给）筛选
- 一键标记已处理

### 7. 角色权限控制
三种角色，不同入口：
- **代理经理 (manager)**: 全局管理、费用审批、回款确认
- **现场协调 (field)**: 靠泊安排、船员换班、补给申请
- **单证专员 (doc)**: 证件审核、单据处理

## 实现取舍点

### 已做的取舍
1. **数据库选择**: 使用 SQLite 而非 MySQL/PostgreSQL
   - 优点: 零配置、嵌入式、适合原型
   - 缺点: 并发性能有限、不适合大规模部署

2. **认证方式**: JWT 存储在 localStorage
   - 优点: 实现简单、无状态
   - 缺点: XSS 风险、无法主动撤销

3. **权限控制**: 基于角色的简单权限 (RBAC)
   - 优点: 逻辑清晰、易于理解
   - 缺点: 不支持细粒度数据权限

4. **前端架构**: 纯客户端渲染 (CSR)
   - 优点: 开发快速、交互流畅
   - 缺点: SEO 不友好、首屏加载慢

## API 接口列表

### 认证
- `POST /api/auth/login` - 登录
- `POST /api/auth/register` - 注册

### 靠泊计划
- `GET /api/berth-plans` - 获取靠泊计划列表
- `GET /api/berth-plans/:id` - 获取靠泊计划详情
- `POST /api/berth-plans` - 创建靠泊计划
- `PUT /api/berth-plans/:id` - 更新靠泊计划
- `POST /api/berth-plans/:id/services` - 添加服务
- `POST /api/berth-plans/:id/communications` - 添加沟通记录

### 费用垫付
- `GET /api/payments` - 获取垫付费用列表
- `GET /api/payments/:id` - 获取垫付费用详情
- `POST /api/payments` - 创建垫付费用
- `POST /api/payments/:id/collections` - 登记回款
- `POST /api/payments/:id/communications` - 添加沟通记录

### 船员换班
- `GET /api/crew-changes` - 获取船员换班列表
- `POST /api/crew-changes` - 创建船员换班
- `PUT /api/crew-changes/:id` - 更新船员换班

### 补给管理
- `GET /api/supplies` - 获取补给列表
- `POST /api/supplies` - 创建补给申请
- `PUT /api/supplies/:id` - 更新补给申请

### 提醒
- `GET /api/alerts` - 获取提醒列表
- `GET /api/alerts/summary` - 获取提醒统计
- `PUT /api/alerts/:id` - 更新提醒状态
