# 礼品定制 - 发货拆单与回执汇总系统

> 解决礼品定制行业「打样确认→量产排期→发货拆单→回执汇总→售后补单」全链路信息分散问题，实现一线处理和管理回看基于同一套数据。

## 系统特性

### 核心业务流程
- **订单管理**：订单创建、打样确认、版本覆盖追踪（自动标记需回查）
- **发货拆单**：智能拆单、实时漏件检测、子单发货确认
- **回执汇总**：右侧滑入面板快速录入、正常签收/异常标记
- **回查面板**：全局时间线、事件追溯、责任链可视化
- **退款处理**：强制责任链绑定、财务→管理层两级审批

### 交互体验
- **角色切换**：跟单员、仓管员、财务员、管理层四角色权限分离
- **首页仪表盘**：待处理、已驳回、需回查数据概览
- **完整状态处理**：空态插画引导、错误态重试、骨架屏加载
- **数据持久化**：基于 localStorage + Zustand，刷新不丢失

### 主场景覆盖
1. **版本覆盖检测**：确认版本被修改时自动记录覆盖人、时间、原因，标记「需回查」
2. **拆单漏件告警**：拆单后自动核对原订单品项，遗漏项标红并触发回查
3. **退款责任链**：退款申请必须绑定责任环节（跟单遗漏/仓管错发/物流损坏等），不可跳过

## 技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Vite 5
- **状态管理**：Zustand 4.5.4（带 persist 中间件）
- **路由**：React Router v6
- **样式**：Tailwind CSS 3.4.4
- **工具库**：date-fns、nanoid

## 演示入口与初始化

### 初始化方式
系统首次启动时自动初始化演示数据，包含：
- 6个演示订单（覆盖各状态）
- 3个拆单记录
- 2个回执记录
- 1个退款申请（含责任链）
- 11条时间线事件

如需重置演示数据：
1. 打开浏览器开发者工具（F12）
2. 进入 Application → Local Storage → http://localhost:3000
3. 删除所有存储项
4. 刷新页面

### 演示场景入口

| 场景 | 访问路径 | 说明 |
|------|---------|------|
| 首页仪表盘 | `/` | 查看待处理、已驳回、需回查统计 |
| 版本覆盖演示 | `/orders/ord-003` | 教育培训中心订单，版本2覆盖了版本1 |
| 拆单漏件演示 | `/split/ord-001` | 科技创新订单，S02单存在漏件风险 |
| 异常签收演示 | `/receipts` | 医疗健康订单，签收异常需处理 |
| 退款责任链演示 | `/refunds` | 医疗健康订单，退款申请待管理层确认 |
| 全局回查面板 | `/review` | 查看所有操作时间线和责任追溯 |

### 角色切换说明

系统内置4种角色，可在顶部导航栏右侧切换：

| 角色 | 权限范围 |
|------|---------|
| **跟单员** | 创建/编辑订单、录入回执、申请退款 |
| **仓管员** | 拆单发货、确认发货、录入回执 |
| **财务员** | 审核退款申请（一级审批） |
| **管理层** | 所有权限 + 退款最终审批 + 数据导出 |

## 项目结构

```
src/
├── components/
│   ├── common/          # 通用组件（空态、错误态、状态标签等）
│   └── layout/          # 布局组件（侧边栏、顶部栏）
├── pages/               # 业务页面
│   ├── Dashboard.tsx    # 首页仪表盘
│   ├── OrderList.tsx    # 订单列表
│   ├── OrderDetail.tsx  # 订单详情
│   ├── SplitOrder.tsx   # 发货拆单
│   ├── Receipts.tsx     # 回执汇总
│   ├── ReviewPanel.tsx  # 回查面板
│   └── Refunds.tsx      # 退款处理
├── store/               # Zustand 状态管理
│   ├── roleStore.ts     # 角色状态
│   ├── orderStore.ts    # 订单状态（含时间线）
│   ├── splitStore.ts    # 拆单状态（含漏件检测）
│   ├── receiptStore.ts  # 回执状态
│   └── refundStore.ts   # 退款状态（含责任链）
├── types/               # TypeScript 类型定义
├── data/                # Mock 演示数据
├── App.tsx              # 路由配置
├── main.tsx             # 应用入口
└── index.css            # 全局样式
```
