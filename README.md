# 水果批发客诉赔付与复检登记系统

## 项目概述

本系统为水果批发行业提供客诉赔付与复检登记一体化解决方案，解决流程分散、损耗说不清、赔付无证据、回款滞后等核心问题。

## 技术栈

- **前端**: Vue 3 + TypeScript + Vite + Pinia + Element Plus + Tailwind CSS
- **后端**: NestJS + TypeScript + TypeORM
- **数据库**: PostgreSQL 14+
- **容器**: Docker + Docker Compose

## 快速启动

### 1. 启动数据库

```bash
cd docker
docker-compose up -d
```

数据库将在 `localhost:5432` 启动，自动执行初始化脚本创建表结构和演示数据。

### 2. 启动后端服务

```bash
cd backend
npm install
npm run start:dev
```

后端服务将在 `http://localhost:3000` 启动。

### 3. 启动前端服务

```bash
cd frontend
npm install
npm run dev
```

前端服务将在 `http://localhost:5173` 启动。

## 演示账号

系统预置了三个角色的演示账号，密码均为 `123456`：

| 角色 | 用户名 | 权限说明 |
|------|--------|----------|
| 档口负责人 | `manager` | 完整操作权限：登记客诉、发起复检、审批赔付、批量复核 |
| 配货员 | `picker` | 登记复检信息、上传证据、更新状态 |
| 财务记账 | `accountant` | 查看赔付记录、登记回款、财务数据统计 |

## 角色切换方式

在登录页面使用不同的用户名登录即可切换角色：

1. **档口负责人视角**：可看到所有菜单，执行批量操作和赔付审批
2. **配货员视角**：只能看到批量复核面板、新建客诉和历史记录
3. **财务记账视角**：只能看到批量复核面板、赔付审批、回款跟踪和历史记录

## 核心功能

### 1. 批量复核面板（首页）
- 统计卡片展示：总客诉、待处理、待回款、已完成
- 卡片式任务列表展示客诉+复检关联任务
- 支持搜索、状态筛选
- 支持批量选中和批量操作（仅档口负责人）
- 点击任务卡片侧滑显示详情，不离开主工作区

### 2. 客诉登记
- 录入客户信息、客诉类型、问题描述
- 关联过磅单号和冷库编号
- 支持多种客诉类型选择

### 3. 复检登记
- 复检人员、冷库位置、复检时间
- 分级结果判定（A/B/C级/不合格）
- 损耗比例和金额计算
- 自动推动状态流转到赔付审批

### 4. 赔付审批
- 赔付金额核算
- 赔付方式选择（退款、抵扣货款、补发货物等）
- 一键批准/驳回
- 自动记录审批人和时间

### 5. 回款跟踪
- 回款金额登记
- 回款方式记录（现金、转账、账扣等）
- 完成后自动结案

### 6. 历史记录
- 完整操作日志时间线
- 状态变更记录
- 操作人和时间戳
- 支持搜索和查看详情

## 数据流转

```
客诉登记 → 复检登记 → 赔付审批 → 回款登记 → 结案
    ↓          ↓          ↓          ↓
  状态日志   状态日志   状态日志   状态日志
```

所有状态变更均完整记录，支持完整追溯。

## 轻量实现说明（边界处理）

以下功能当前采用轻量实现方式：

1. **权限控制**：采用角色级权限控制，暂未实现细粒度按钮级权限
2. **消息通知**：暂未实现消息推送，需要手动刷新页面获取最新数据
3. **报表功能**：仅基础统计展示，暂未实现复杂报表导出
4. **审批流程**：采用单级审批，档口负责人直接审批，暂未实现多级审批
5. **证据上传**：暂未实现文件上传功能，留待后续扩展
6. **打印功能**：暂未实现单据打印功能

## 开发说明

### 数据库初始化

`docker/init.sql` 包含：
- 数据库表结构创建
- 索引创建
- 3个演示用户（不同角色）
- 10条演示客诉数据
- 复检、赔付、回款演示数据
- 状态变更历史记录

### API 接口

- `POST /api/auth/login` - 登录
- `GET /api/auth/me` - 获取当前用户信息
- `GET /api/complaints` - 客诉列表
- `POST /api/complaints` - 创建客诉
- `GET /api/complaints/:id` - 客诉详情
- `POST /api/complaints/batch` - 批量操作
- `POST /api/rechecks` - 创建复检
- `POST /api/compensations` - 创建赔付申请
- `POST /api/compensations/:id/approve` - 批准赔付
- `POST /api/compensations/:id/reject` - 驳回赔付
- `POST /api/payments` - 登记回款

## 常见问题

### 1. 数据库连接失败
确保 Docker 容器已启动，检查端口 5432 是否被占用。

### 2. 前端无法调用后端接口
检查后端服务是否在 3000 端口运行，Vite 代理配置是否正确。

### 3. 演示数据不显示
首次启动 Docker 时会自动执行 init.sql，如果没有数据可以删除 docker 卷重新启动：
```bash
cd docker
docker-compose down -v
docker-compose up -d
```
