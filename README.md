# 留学服务系统 - 文书流转与截点提醒

## 系统概述

本系统旨在解决留学服务行业中普遍存在的问题：
- **入口散**：信息分散在共享盘、待办表、家长群中
- **提醒弱**：截止日期漏盯、补件版本混乱
- **历史难找**：退款协商等问题缺乏完整上下文追踪

## 核心功能

### 1. 角色入口设计

**顾问主管 (Consultant Manager)**
- 查看所有学生的全局视角
- 问题追踪与退款协商
- 整体进度监控

**文案老师 (Copywriter)**
- 专注于分配给自己的文书任务
- 版本管理与审核流程
- 文书状态流转

**签证助理 (Visa Assistant)**
- 签证材料进度管理
- 面签预约与进度记录
- 资金证明等材料审核

### 2. 文书流转工作流

```
待处理 → 进行中 → 审核中 → 已通过
               ↓
            已拒绝 (退回修改)
```

- **版本追踪**：完整记录每次上传的版本、上传人、时间、备注
- **反馈闭环**：审核意见直接关联到文档，历史可追溯
- **截点联动**：文档通过后自动完成关联的截点任务

### 3. 截点提醒与日历视图

- **三色预警**：
  - 🔴 红色：已逾期 (Overdue)
  - 🟡 黄色：7天内到期 (Upcoming)
  - 🔵 蓝色：正常 (Normal)

- **月视图**：直观展示所有截点分布
- **类型筛选**：按材料提交、申请截止、签证预约等分类查看
- **快速跳转**：点击截点直接进入学生详情页

### 4. 问题追踪系统

专门解决：截止日漏盯、补件版本混乱、退款协商缺上下文

**问题分类**：
- 版本混乱 (Document Version)
- 截点错过 (Deadline Missed)
- 退款协商 (Refund Negotiation)
- 签证问题 (Visa Issue)
- 沟通问题 (Communication)

**处理历史**：完整记录每次状态变更、操作人、时间、备注

## 技术实现取舍

### ✅ 已实现 (核心价值)

1. **内存数据存储**
   - 取舍原因：快速验证产品价值，无需数据库依赖
   - 特点：服务重启数据重置，适合演示
   - 改进方向：接入 PostgreSQL/MySQL

2. **JWT + Cookie 认证**
   - 取舍原因：简单有效，前后端分离友好
   - 特点：HttpOnly Cookie 防 XSS
   - 改进方向：接入 Redis 实现 Token 黑名单

3. **角色权限控制**
   - 取舍原因：基于角色的数据过滤，而非精细权限
   - 特点：不同角色看到不同的学生列表
   - 改进方向：引入 RBAC 权限系统

4. **响应式 UI 设计**
   - 取舍原因：优先桌面端体验（内部系统）
   - 特点：移动端可用但非优化
   - 改进方向：针对移动端优化布局

### ⚠️ 简化处理 (当前限制)

1. **无真实文件上传**
   - 当前：仅记录文件元数据，无实际文件存储
   - 建议：接入 AWS S3 / 阿里云 OSS

2. **无实时通知**
   - 当前：页面刷新获取最新数据
   - 建议：接入 WebSocket / Server-Sent Events

3. **无邮件/短信提醒**
   - 当前：仅系统内视觉提醒
   - 建议：集成邮件、企业微信、短信通知

4. **无审计日志**
   - 当前：仅学生维度的操作历史
   - 建议：全系统审计日志，支持合规追溯

## API 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/login | 登录 |
| POST | /api/auth/logout | 登出 |
| GET | /api/auth/me | 获取当前用户 |
| GET | /api/students | 学生列表 (支持筛选) |
| GET | /api/students/:id | 学生详情 (含关联数据) |
| GET | /api/documents/student/:id | 学生文档列表 |
| PUT | /api/documents/:id/status | 更新文档状态 |
| POST | /api/documents/:id/versions | 上传新版本 |
| GET | /api/deadlines | 截点列表 (支持时间范围) |
| GET | /api/issues | 问题列表 |
| PUT | /api/issues/:id | 更新问题 |
| GET | /api/messages/student/:id | 消息列表 |
| POST | /api/messages/student/:id | 发送消息 |
