# 胶片冲扫管理系统

基于 Nuxt 3 + FastAPI 的胶卷登记与冲扫排队管理系统，解决了胶卷登记、冲扫进度跟踪、异常处理和返工确认等核心业务痛点。

## 核心功能

### 📊 仪表总览
- 今日新增、进行中、待处理异常、返工中数据统计
- 工序进度可视化图表
- 实时动态时间线

### 📋 胶卷队列
- 所有胶卷冲扫进度一览
- 支持按状态筛选和关键词搜索
- 工序进度条直观展示

### 🔍 连续回查面板（核心功能）
- **一站式处理**：时间线、异常记录、备注沟通、操作处理
- **异常管理**：异常登记、分级处理、解决记录
- **返工确认**：返工原因、范围记录，次数统计
- **操作处理**：工序进度更新、状态流转

### ➕ 胶卷登记
- 完整的客户和胶卷信息录入
- 费用管理
- 优先级设置

## 启动方式

### 1. 启动后端服务

```bash
# 安装依赖
pip3 install -r backend/requirements.txt

# 生成演示数据（包含异常场景）
python3 backend/init_data.py

# 启动 FastAPI 服务
python3 backend/main.py
```

后端服务地址：http://localhost:8000

API 文档：http://localhost:8000/docs

### 2. 启动前端服务

```bash
# 安装依赖
cd frontend && npm install

# 启动 Nuxt 3 开发服务
npm run dev
```

前端服务地址：http://localhost:3000

## 技术栈

- **前端**：Nuxt 3 + TypeScript + Tailwind CSS
- **后端**：FastAPI + Pydantic + Python-JOSE
- **认证**：JWT Token
