# 光伏运维 - 缺陷登记与整改回查系统

基于 SvelteKit + Go Fiber 构建的多人协作光伏运维管理系统，解决 Excel、截图、微信群信息碎片化问题。

## 系统特性

### 🎯 核心功能
- **首页看板**：一屏展示待处理、已驳回、需回查数据统计
- **缺陷全流程管理**：登记 → 派单 → 处理 → 审核 → 关闭 → 回查
- **状态时间轴**：每次状态变更完整记录，操作人、时间、备注一目了然
- **停机时长追踪**：自动记录设备停机开始/结束时间，累计统计
- **批量操作**：支持批量更新状态，高峰期高效处理

### 👥 角色权限设计
| 角色 | 权限说明 |
|------|----------|
| **站长** | 派单、审核通过、驳回、标记需回查 |
| **巡检工程师** | 登记缺陷、开始处理、提交整改 |
| **运维内勤** | 查看数据、导出报表（基础查看权限） |

## 🚀 快速开始

### 环境要求
- Go >= 1.21
- Node.js >= 18

### 步骤 1：启动后端服务

```bash
cd backend

# 安装依赖
go mod download

# 启动服务（端口 8080）
go run .
```

后端启动后会自动：
- 创建 SQLite 数据库 `pvops.db`
- 初始化 3 个测试用户（张站长、李工、王内勤）
- 初始化备件数据

### 步骤 2：启动前端服务

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器（端口 5173）
npm run dev
```

### 步骤 3：访问系统

打开浏览器访问：**http://localhost:5173**

## 📖 使用说明

### 角色切换
在左侧边栏底部点击「当前角色」可切换不同身份，体验不同权限：
- 站长（station_master）
- 巡检工程师（inspector）  
- 运维内勤（admin）

### 标准流程演示

1. **登记缺陷**（巡检工程师）
   - 进入「缺陷管理」→ 点击「登记缺陷」
   - 填写标题、位置、优先级、描述

2. **派单**（站长）
   - 切换到「站长」角色
   - 打开缺陷详情 → 点击「派单」→ 选择处理人

3. **处理整改**（巡检工程师）
   - 切换到「巡检工程师」角色
   - 点击「开始处理」→ 完成后「提交整改」

4. **审核关闭**（站长）
   - 切换到「站长」角色
   - 「审核通过」关闭工单，或「驳回」要求重新处理

5. **标记回查**（站长）
   - 对需要复查的缺陷，点击「标记需回查」

### 批量操作
- 在缺陷列表勾选多条记录
- 点击「批量处理」按钮
- 选择目标状态并添加备注

## 📊 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/defects` | 获取缺陷列表 |
| GET | `/api/defects/:id` | 获取缺陷详情（含历史） |
| POST | `/api/defects` | 创建缺陷 |
| PUT | `/api/defects/:id/status` | 更新缺陷状态 |
| POST | `/api/defects/batch-status` | 批量更新状态 |
| GET | `/api/users` | 获取用户列表 |
| GET | `/api/spare-parts` | 获取备件列表 |

## 🔄 缺陷整改完整链路

```
待处理 → 已派单 → 处理中 → 待审核 → 已关闭
                           ↓        ↑
                         已驳回   需回查
```

### 批量派单
- 勾选多条待处理缺陷，一键批量派单给指定工程师
- 处理人信息自动写入缺陷记录和历史时间轴

### 备件领用管理
- 处理中状态下可领用备件
- 自动扣减库存，库存不足时提示
- 领用记录完整保存：备件名称、型号、数量、领用人、时间、备注
- 详情页可回看所有备件去向
- 领用操作记入状态时间轴

### 演示数据说明
首次启动（数据库为空时）自动创建演示数据：
- **3条待处理** - 组件发热、汇流箱通讯中断、逆变器异响
- **1条已驳回** - 接地电阻测试不合格（附驳回原因）
- **1条需回查** - 组件玻璃碎裂（已更换，待回访）
- **1条处理中** - MC4接头老化（可领用备件）

## 🎨 设计亮点

1. **状态时间轴** - 完整追溯每一次操作，复盘不再翻聊天记录
2. **停机自动计时** - 开始处理时记录，关闭时自动计算时长
3. **角色感知操作** - 根据当前角色显示可用动作，界面简洁
4. **批量处理** - 支持多选项批量派单/改状态，高峰期也能快处理
5. **首页一目了然** - 待处理、已驳回、需回查分区展示
6. **备件全追踪** - 从库存扣减到领用明细，去向完整可查
