# 🚀 乐器租赁系统 - 启动说明

## 📋 环境要求
- Node.js >= 16.x
- npm 或 yarn
- SQLite（已内置，无需额外安装）

## 🛠️ 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 初始化数据库
```bash
# 生成Prisma客户端并推送数据库结构
npm run db:init
```

### 3. 生成演示数据
```bash
npm run db:seed
```

### 4. 启动开发服务器
```bash
npm run dev
```

服务器将在 `http://localhost:3001` 启动

## 📦 生产环境部署
```bash
# 构建TypeScript
npm run build

# 启动生产服务器
npm start
```

## 🔌 API 调用方式

### 1. 登录获取 Token
```bash
curl -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"owner","password":"123456"}'
```

响应示例：
```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": "uuid",
      "username": "owner",
      "name": "张老板",
      "role": "STORE_OWNER"
    }
  }
}
```

### 2. 调用业务接口
在请求头中携带 Token：
```bash
curl http://localhost:3001/api/rentals \
  -H "Authorization: Bearer <your-token>"
```

### 3. 幂等性支持
所有写操作接口支持幂等性，在请求头中添加 `x-idempotency-key`：
```bash
curl -X POST http://localhost:3001/api/rentals \
  -H "Authorization: Bearer <your-token>" \
  -H "x-idempotency-key: <unique-key>" \
  -H "Content-Type: application/json" \
  -d '{...}'
```

## 📝 主要接口列表

### 认证接口
- `POST /api/auth/login` - 登录
- `GET /api/auth/me` - 获取当前用户信息

### 租赁管理
- `GET /api/rentals` - 租赁单列表
- `GET /api/rentals/:id` - 租赁单详情
- `POST /api/rentals` - 创建租赁单
- `POST /api/rentals/:id/return` - 归还乐器

### 押金管理
- `GET /api/deposits` - 押金单列表
- `GET /api/deposits/:id` - 押金单详情
- `POST /api/deposits/:id/settle` - 结算押金
- `POST /api/deposits/:id/dispute` - 标记押金争议

### 损坏申诉
- `GET /api/damage-claims` - 申诉列表
- `GET /api/damage-claims/:id` - 申诉详情
- `POST /api/damage-claims` - 创建损坏申诉
- `POST /api/damage-claims/:id/dispute` - 客户提交申诉
- `POST /api/damage-claims/:id/reject` - 驳回申诉
- `POST /api/damage-claims/:id/resolve` - 通过申诉（重新判责）
- `POST /api/damage-claims/:id/close` - 结案
- `GET /api/damage-claims/:id/evidence` - 获取证据链

### 维修管理
- `GET /api/maintenances` - 维修单列表
- `GET /api/maintenances/:id` - 维修单详情
- `POST /api/maintenances` - 创建维修单
- `POST /api/maintenances/:id/complete` - 完成维修
- `GET /api/maintenances/summary` - 费用汇总

### 通用接口
- `GET /api/instruments` - 乐器列表
- `GET /api/customers` - 客户列表
- `GET /api/audit-logs` - 审计日志
- `GET /api/audit-logs/:entityType/:entityId` - 实体审计追踪
- `GET /api/notes/:entityType/:entityId` - 备注列表
- `POST /api/notes` - 添加备注
- `POST /api/notes/supplement` - 补录备注（仅老板）

## 🐛 故障排查

### 数据库连接问题
- 检查 `.env` 文件中的 `DATABASE_URL` 配置
- 默认使用 SQLite: `file:./dev.db`

### 端口被占用
- 修改 `.env` 文件中的 `PORT` 配置
- 默认端口: 3001

### TypeScript 编译错误
- 运行 `npx tsc --noEmit` 查看详细错误
- 确保安装了正确版本的依赖
