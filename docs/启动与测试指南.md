## 二、启动步骤

### 2.1 后端服务启动

```bash
cd server

# 1. 安装依赖
npm install

# 2. 初始化数据库和样例数据
npm run seed

# 3. 启动开发服务器（端口 3001）
npm run dev

# 或生产模式
npm run build
npm start
```

**服务地址：** http://localhost:3001
**API 文档：** 见 `TECH-高尔夫练习场会员储值与消耗对账系统.md`

### 2.2 前端服务启动

```bash
cd client

# 1. 安装依赖
npm install

# 2. 启动开发服务器（端口 3000）
npm run dev

# 或生产构建
npm run build
npm start
```

**前端地址：** http://localhost:3000

### 2.3 环境变量配置

**后端 `.env`（可选，有默认值）：**
```
PORT=3001
JWT_SECRET=golf-secret-key-change-in-production
DB_PATH=./data/golf.db
```

**前端 `.env.local`（可选，有默认值）：**
```
NEXT_PUBLIC_API_BASE_URL=http://localhost:3001/api
```

### 4.2 问题流测试 1 - 消费争议处理

**测试目标：** 验证异常工单的创建、处理流程，以及过程留痕是否完整。

**背景：** 会员郑小刚（ID=8，普通会员）昨日打球被系统扣减 160 元，但他实际只打了 1 小时应扣 80 元，前来投诉。

**测试步骤：**

1. **创建异常工单（前台）**
   - 使用 `reception1` 登录
   - 进入前台工作台，搜索会员「郑小刚」
   - 查看交易流水，找到昨天的消费记录（ID=12，¥160）
   - 点击「创建异常工单」
   - 类型：账单争议
   - 描述：会员称只打了 1 小时，系统扣了 2 小时费用 ¥160
   - 关联交易：选择 ID=12
   - 关联预约：选择 ID=5
   - 提交工单

2. **处理异常工单（场馆经理）**
   - 使用 `manager` 登录
   - 进入「异常处理」
   - 找到刚才创建的工单（状态：待处理）
   - 点击查看详情
   - **关键验证：** 右侧详情面板自动展示郑小刚的全链路时间线
     - 可以看到他的储值记录、预约记录、消费记录、器材借还记录
     - 按时间倒序排列，点击可展开查看详细数据
   - 核实：确实是前台操作失误，预约时选成了 2 小时，实际只打了 1 小时

3. **调账处理**
   - 点击「处理工单」
   - 新状态：处理中
   - 处理结果：核实为前台操作失误，需调账 +¥80
   - 点击「确认调账」
   - 调账金额：+80 元
   - 调账类型：退还到本金
   - 调账原因：操作失误，多扣 1 小时费用
   - 确认调账
   - 预期：
     - 郑小刚本金余额增加 ¥80
     - 交易 ID=12 的对账状态变为「已调账」
     - 生成一条调账流水记录

4. **完成工单**
   - 再次点击「处理工单」
   - 新状态：已解决
   - 处理结果：已调账完成，退还 ¥80 到本金账户
   - 确认
   - 预期：工单状态变为「已解决」

5. **验证操作留痕**
   - 进入「操作日志」
   - 筛选模块：异常工单
   - 找到刚才的操作
   - 查看详情
   - 预期：
     - 记录了工单创建：状态从 null → 待处理
     - 记录了状态变更：待处理 → 处理中
     - 记录了调账：前后金额对比
     - 记录了工单完成：处理中 → 已解决
   - 所有操作都有操作人、时间戳、操作前后数据

## 六、常见问题

### Q1: 数据库在哪里？
A: SQLite 数据库文件位于 `server/data/golf.db`，删除该文件然后运行 `npm run seed` 即可重置数据。

### Q2: 如何重置样例数据？
A: 
```bash
cd server
rm -f data/golf.db
npm run seed
```

### Q3: 前端 API 请求地址如何修改？
A: 修改 `client/.env.local` 中的 `NEXT_PUBLIC_API_BASE_URL`。

### Q4: 如何修改 JWT Token 有效期？
A: 修改 `server/src/middleware/auth.ts` 中的 `expiresIn` 参数。

### Q5: 如何修改扣减优先级？
A: 登录场馆经理账号，进入「口径配置」页面，修改「储值扣减优先级」即可即时生效。

## 七、API 快速测试

使用 curl 测试后端 API 是否正常：

```bash
# 1. 登录获取 Token
curl -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"manager","password":"123456"}'

# 2. 获取会员列表（需要替换上面返回的 token）
curl http://localhost:3001/api/members \
  -H "Authorization: Bearer YOUR_TOKEN"

# 3. 获取当前用户信息
curl http://localhost:3001/api/auth/me \
  -H "Authorization: Bearer YOUR_TOKEN"
```
